# Visual Direction

## Visual Thesis

Два последовательных одинаковых нативных выбора: сначала производитель, затем точный паспорт телевизора.

## Direction Options

1. Выбранная faithful-правка: повторить уже утверждённый brand-select на шаге модели.
2. Не выбрано: длинная сетка карточек моделей — нарушает требование пользователя и создаёт простыню.
3. Не выбрано: searchable combobox — это текущий вариант, который пользователь попросил заменить.

## Selected Direction

Вариант 1: визуальная симметрия и нативное управление без нового паттерна.

## Hierarchy And Reading Order

Марка → модель → стена → механизм; на каждом из первых двух шагов одно решение и одна primary action.

## Composition And Negative Space

Сохраняются существующие отступы, широкое поле, отдельная строка количества и свободное пространство вокруг решения.

## Palette And Typography

`paper`, `panel`, `ink`, `line`, `action`; Roboto Condensed для заголовков и IBM Plex Sans для управления.

## Responsive Or Sequence Behavior

На 320 px поле и кнопка идут одной колонкой, с `lg` — поле и кнопка в строку. Названия моделей переносятся внутри option средствами браузера; control ограничен контейнером.

## Exact-content Layer

Подпись, placeholder и названия моделей формируются детерминированно из проверенного каталога.

## Imagegen Layer And Invariants

None. Новая графика и imagegen не нужны.
