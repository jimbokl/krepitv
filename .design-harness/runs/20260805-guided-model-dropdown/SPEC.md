# Design Specification

## Context

Первый шаг `/podbor/` уже использует нативный выпадающий список марок, а второй по-прежнему использует текстовый `ModelSearch`.

## Goal

Сделать второй шаг визуально и поведенчески симметричным первому: нативный выпадающий список моделей выбранной марки.

## Non-goals

Новые URL, поиск по всему каталогу, изменение паспортов моделей, совместимости, аналитики, коммерческого ранжирования или партнёрских выходов.

## Inputs

`catalog.models` — проверенные паспорта и точные идентификаторы; query-параметр `model` — безопасная глубокая ссылка.

## Constraints

Только русский интерфейс. Модели вычисляются из текущего каталога и строго фильтруются по выбранной марке. Свежий шаг модели не подставляет первую модель. Deep link может предварительно выбрать точную модель.

## States

Default/disabled/empty — шаг модели без выбранного значения; focus — видимый фокус select. Loading/error/success относятся к неизменённому локальному расчёту на шаге четыре.

## Acceptance tests

- После выбора марки второй шаг содержит `select#guided-tv-model`, а не текстовое поле.
- Select содержит только модели выбранной марки и одну пустую опцию.
- Кнопка продолжения disabled, пока модель не выбрана.
- Смена марки очищает модель, стену, механизм и старый результат.
- Модель другой марки нельзя подтвердить через событие или подмену DOM.
- `?model=<точный-id>` открывает шаг два с соответствующей выбранной моделью.
- SSR показывает порядок «марка → модель» без случайной модели.
- 320, 768 и 1440 CSS px, а также 200% текста не имеют горизонтального переполнения.

## Allowed files

Совпадают с `task.json`: мастер, flow-тест, QA-capture, Rust sitegen, `docs/` и evidence-пакет.

## Verification commands

Контрактные flow/result/privacy тесты и Rust SSR-тест; полный `npm run build`; design drift scan.

## Sources and claims

Опции происходят из `data/research/verified-tv-models.json`; новых внешних утверждений нет.

## Asset contract

Новых графических активов нет. Используются существующие Tailwind-токены, нативный select, CaretDown и детерминированный русский текст.

## Review and rollback

Независимая headless-browser проверка всех состояний и трёх viewport. Rollback — откат release-коммита, пересборка `docs/` и повторный Pages deploy.
