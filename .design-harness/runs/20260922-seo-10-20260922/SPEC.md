# Design Specification

## Context
По Wordstat подтверждены десять различимых задач, которых нет среди 132 существующих SEO-материалов. Поисковые консоли уже дают проекту показы и клики, поэтому спринт расширяет семантику полезными инструментами без шаблонных клонов.

## Goal
Опубликовать десять самостоятельных страниц с конкретным Rust/WASM-помощником, таблицей решений, ограничениями, официальными источниками и контекстной перелинковкой.

## Non-goals
Редизайн, массовые геостраницы, модельные клоны, сбор персональных данных, загрузка файлов, универсальные сервисные коды и неподтверждённая совместимость.

## Inputs
data/seo_pages.json, Wordstat-снимок 22.09.2026, официальные инструкции Apple, Sony, Samsung и TCL, DESIGN.md, существующий ConnectionHelper.

## Constraints
Русский публичный текст; Tailwind и утверждённые токены; расчёт веток в локальном Rust/WASM; статический GitHub Pages; ответы формы не отправляются на сервер и не попадают в аналитику. SSR обязан содержать самостоятельный ответ, таблицу, источники и ссылку на смежный материал.

## States
default и empty: поля не выбраны. disabled: кнопка недоступна до трёх ответов. focus: видимый native focus. loading: блокировка повторной отправки. error: понятный повтор без потери страницы. success: план с шагами и ограничением. Неизвестное оборудование даёт needs_review, а не положительное заключение. Клавиатура и адаптивные состояния обязательны.

## Acceptance tests
На 320/768/1440 px нет горизонтального overflow и наложений. Все label связаны с select. Tab и Enter работают. Результат объявляется через aria-live. Смена ответа очищает старый результат. Loading исключает повтор. Каждая страница имеет уникальные title/H1/lead/FAQ/таблицу, минимум два уместных источника либо явно ограниченный первичный источник, входящую ссылку и один canonical. Секреты и ответы пользователя отсутствуют в HTML и событиях.

## Allowed files
web, crates/engine/src, crates/sitegen/src, data, scripts/qa, scripts/verify.mjs, .design-harness, product-docs, docs.

## Verification commands
npm run build
node scripts/qa/seo-10-20260922.mjs

## Sources and claims
Источники и даты зафиксированы в task.json и на страницах. Производитель подтверждает только описанный интерфейс или процедуру; одна модель и один бренд не доказывают универсальность. Wordstat показывает спрос, а не прогноз посещений.

## Asset contract
HTML/JSX и текстовые результаты Rust. Скриншоты PNG 320×800, 768×1024, 1440×900. Новые изображения и цвета не создаются: существующий интерфейс сильнее для пошаговой диагностики.

## Review and rollback
Независимый reviewer проверяет реальные скриншоты, код, источники и закрытые ветки. Откат — revert только коммита спринта, полный build и повторный Pages deploy без reset пользовательской рабочей копии.
