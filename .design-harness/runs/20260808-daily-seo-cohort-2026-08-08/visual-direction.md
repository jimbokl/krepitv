# Visual Direction

## Visual Thesis

Сохранить утверждённый редакционный industrial-стиль KREPI TV: крупный чёрный заголовок, красный сигнал действия, бумажный фон, жёсткие рамки и моноширинные метки.

## Direction Options

1. Полностью повторно использовать SeoEvidenceGuide.
2. Добавить отдельные карточки для каждого материала.
3. Создать новые иллюстрации стены и кабелей.

## Selected Direction

Вариант 1: он сохраняет визуальную непрерывность, уменьшает вес страниц и делает ежедневные когорты сравнимыми.

## Hierarchy And Reading Order

Breadcrumb → H1 и lead → мастер выбора → SSR-таблица → проверочный список → FAQ → официальные источники → связанные материалы.

## Composition And Negative Space

Максимальная ширина 1440 px, длинный текст ограничен 3–4xl, блоки разделены крупными вертикальными интервалами. Таблица имеет собственный горизонтальный scroll, но страница не прокручивается по горизонтали.

## Palette And Typography

Только существующие `paper/ink/action/muted/line`, `font-display` для иерархии и `font-mono` для сигналов и даты проверки.

## Responsive Or Sequence Behavior

На мобильном три кнопки идут колонкой, на md — в три столбца. Неактивное, hover, focus-visible, selected/success и SSR-состояния сохраняются в существующем компоненте.

## Exact-content Layer

Русский H1, шесть фактов, шесть FAQ, три ветки мастера, stop-блок и официальные источники берутся из JSON без генерации в клиенте.

## Imagegen Layer And Invariants

None: новые изображения не используются; это информационные инструменты, и существующая типографика важнее декоративной графики.
