# Visual Direction

## Visual Thesis

Расширение текущего строгого журнально-технического блока без нового декора.

## Direction Options

1. Оставить семь карточек — отклонено: неполный ряд.
2. Девять карточек в 3×3 — выбрано: завершённый ритм и два сильных входа.
3. Создать две новые страницы — отклонено: уже есть более востребованные полные страницы.

## Selected Direction

Девять одинаковых карточек с тонкими разделителями и стрелкой действия.

## Hierarchy And Reading Order

Заголовок и объяснение → 3×3 инструментов → ссылки на каталоги.

## Composition And Negative Space

Три равные колонки desktop и tablet, одна mobile; высота карточек сохраняется.

## Palette And Typography

Без изменений: `paper/ink/line/action`, Roboto Condensed + IBM Plex.

## Responsive Or Sequence Behavior

На 1440 px три ряда по три. На 768 px пять рядов, последний содержит одну
карточку. На 320 px остаются девять последовательных ссылок.

## Exact-content Layer

Названия берутся только из `h1` двух существующих страниц, без рекламного текста.

## Imagegen Layer And Invariants

None: генерация изображений не нужна.
