# Discovery

## Existing Design System

`DESIGN.md` задаёт KREPI TV editorial-палитру и типографику; существующий `seo-editorial-hero` уже охватывает 100 руководств. Каталог рендерится React для гидратации и Rust для статического SEO HTML. Индивидуальные SVG моделей и кронштейнов существуют, но расположены ниже первого экрана.

## Reuse Decisions

Переиспользовать editorial hero и существующие документальные кадры для SEO. Перенести технические SVG в первые экраны карточек без изменения данных. Использовать нативные ссылки и уже существующий каталог/мастера.

## New Primitives And Rationale

Новые примитивы: `technical-editorial-hero` для двух типов паспортных карточек; маленький визуальный блок статуса для непроверенных моделей. Не вводить новую дизайн-систему.

## Risks

Дрейф SSR/React, неработающий якорь, ложная продуктовая фотография, тяжёлые изображения, дублирование SVG, noindex→index или случайная рекомендация для неподтверждённой модели.
