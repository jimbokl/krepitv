# Visual Direction

## Visual Thesis

«Покажи предмет проверки». На паспортной странице это точная условная техническая схема, на бытовой задаче — спокойный контекстный кадр, на noindex-наблюдении — прозрачный статус и маршрут ручной проверки.

## Direction Options

1. Унифицированная фотокарточка на всех страницах — отвергнута как ложная для конкретных моделей.
2. Чисто таблицы и текст — отвергнута как трудная для новичка.
3. Типизированный editorial hero: фото для задачи, техническая схема для товара, статус для неопределённости.

## Selected Direction

Третий вариант. Не унифицировать смысл картинок, унифицировать ритм и читаемость.

## Hierarchy And Reading Order

Заголовок и одно действие → визуальная опора и оговорка → паспортные данные/интерактив → источники и ограничения.

## Composition And Negative Space

Крупный заголовок с ограниченной длиной строки, воздух вокруг схемы, компактная подпись. Никаких повторных плотных карточек в первом экране.

## Palette And Typography

Существующие токены paper/ink/action/technical/verified; font-display для иерархии, текстовые пояснения без мелкого серого шрифта.

## Responsive Or Sequence Behavior

На телефоне текст и действие перед изображением; таблицы и технические схемы без горизонтального переполнения. Фокус ссылки заметен.

## Exact-content Layer

Название модели, VESA, масса и проверка только из каталога; текст подписи схемы объясняет, что это не разметка стены.

## Imagegen Layer And Invariants

Новые генеративные кадры при необходимости только бытовые, без брендов и чисел; для моделей/кронштейнов — уже существующие индивидуальные SVG. Все фото имеют смысловой alt и подпись о границах применимости.
