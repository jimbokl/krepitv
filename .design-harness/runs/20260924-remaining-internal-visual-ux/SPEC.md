# Design Specification

## Context

Первая сотня SEO-руководств уже получила иллюстрированный первый экран; остальные типы страниц пока не имеют единой визуальной иерархии.

## Goal

Завершить визуальный редизайн всех существующих внутренних страниц после первой когорты из 100 материалов. На страницах моделей и кронштейнов главным изображением служит их индивидуальная проверяемая схема; на остальных SEO-страницах — тематический иллюстративный кадр с границей применимости. Служебные и юридические страницы получают ясную иерархию без фиктивной фотографии.

## Non-goals

Не создаём новые URL, не меняем технические данные, индексацию, расчёты или методику. Для 60 noindex-страниц отсутствие рекомендации и CTA на покупку обязательно сохраняется. При выявленном конфликте паспортных VESA блокируем модельные партнёрские офферы до ручной сверки; остальные партнёрские ссылки не меняем.

## Inputs

`DESIGN.md`, `web/AGENTS.md`, `data/seo_pages.json`, `data/internal_visual_pages.json`, `data/tv_models.json`, `data/mounts.json`, шаблоны React и Rust SSR.

## Constraints

Только русский интерфейс; Tailwind и существующие токены; статический GitHub Pages; изображения без выдуманных параметров. Одно и то же изображение не должно притворяться фотографией конкретной модели.

## States

Для новых первых экранов — default и keyboard focus. Они статичны; loading/empty/error/success/disabled не применимы. Интерактивные мастера ниже них не меняются и проходят существующие тесты.

## Acceptance tests

1. Каждый оставшийся SEO ID имеет проверенный смысловой visual theme, корректные alt/подпись и действующий якорь действия; старая когорта из 100 не регрессирует.
2. Каждая из 161 проверенной модели и 25 кронштейнов показывает индивидуальную схему в первом экране, без дублирования схемы ниже; подпись указывает её условность. В модельных страницах виден путь к проверенным совместимым креплениям.
3. Все 60 noindex-наблюдений из текущего набора данных остаются noindex и не получают ложных карточек совместимости, покупки или партнёрских ссылок; визуальное объяснение проверки допустимо.
4. Каталоги и самостоятельные страницы становятся читаемее и визуально последовательны. Юридическая страница не получает нерелевантное фото.
5. `npm run build`, точный аудит HTML/URL/индексации, SSR/React и browser QA на 320/768/1440 px, 200% text, focus проходят. HTTPS production и artifact hashes совпадают после релиза.

## Allowed files

`data/internal_visual_remaining.json`, `web/src/pages/`, `web/src/components/`, `web/src/lib/internalVisualPages.mjs`, `web/src/styles.css`, `web/tests/`, `crates/sitegen/src/main.rs`, `scripts/qa/`, `scripts/verify.mjs`, `scripts/catalog/audit-model-page-quality.mjs`, `tests/qa/`, `web/public/assets/images/`, `product-docs/design-references/`, `.design-harness/runs/20260924-remaining-internal-visual-ux/`, `docs/`, `web/` (зеркало статических SSR-страниц).

## Assets and claims

Индивидуальные SVG паспортных моделей и кронштейнов создаются из проверенных данных; для модели с противоречащими источниками вместо рисунка отверстий выводится предупреждение. Контекстные бытовые кадры — иллюстрации, не фото конкретного товара/места крепления. Точные характеристики и совместимость исходят только из каталога и Rust engine.

## Sources and claims

Модельные характеристики и совместимость — из проверенного каталога и указанного на каждой странице первичного источника. Новых численных или продуктовых утверждений этот спринт не добавляет.

## Review and rollback

Независимый reviewer проверяет охват, отсутствие ложных утверждений, адаптивность и diff перед release. Откат одним revert исходного коммита и повторным Pages deploy.

## Verification commands

`node scripts/qa/verify-remaining-internal-pages.mjs` и `npm run build`, затем браузерные screenshots и production smoke.

## Asset contract

Индивидуальные SVG 1200×630 являются программно генерируемыми техническими диаграммами с HTML-подписью. Существующие WebP 960×640 используются как контекстные иллюстрации. Точный текст, числа и призывы остаются в HTML, не рисуются в bitmap. Новый imagegen нужен только при обнаружении смыслового пробела, не для фотографий товаров.
