# Discovery

## Existing Design System

Обязателен `DESIGN.md`: бумажный фон, чёрные инженерные линии, оранжевое
действие, зелёный результат, Roboto Condensed/IBM Plex Sans/Mono. Повторно
используются `primary-button`, `input-control`, `field-label`, `ResultMetric`,
паттерн режимов и live-region соседних калькуляторов. Источник композиции —
`02-guided-selection.png`.

## Reuse Decisions

Расширить чистый Rust engine и wasm wrapper; добавить один React-компонент по
паттерну `ViewingDistanceCalculator`; подключить его через существующий
`SeoPage`; использовать Rust sitegen для SSR-таблицы, related links и sitemap.

## New Primitives And Rationale

Новая доменная структура результата нужна, потому что существующий viewing
calculator связывает диагональ с расстоянием и не принимает пару фактических
размеров. Новых визуальных примитивов не требуется.

## Risks

Простой bidirectional-конвертер уже есть у FrameRateTest, ToolFox, Compera и
Калькуляторов.ру. Поэтому собственный клин — сравнение двух диагоналей, ниша с
заданным зазором и проверка паспортного корпуса выбранной модели. Второй риск —
каннибализация со страницей расстояния и mount-страницами 43/55/65″. Новый URL
употребляет только лексику физического размера/перевода; расстояние и подбор
кронштейна остаются следующими работами.
