# Design Specification

## Context

Сайт уже отправляет приватно-безопасные события готового результата, перехода к
кронштейну, действия со сводкой и перехода на Маркет, но не фиксирует начало
работы с каждым инструментом. Текущий opt-in баннер почти не даёт данных.

## Goal

Добавить измеримую воронку инструментов и заменить блокирующую необходимость
явного разрешения компактным уведомлением о включённой аналитике с отказом.

## Non-goals

Новые URL, новые инструменты, Webvisor/clickmap, сбор полей форм, рекламные и
коммерческие изменения.

## Inputs

Существующие tool_id из emitResultCompleted; текущая Яндекс Метрика; компоненты
MetrikaConsent, metrikaGate, metrika и приватный funnel report.

## Constraints

Только русский публичный текст. События содержат только action, tool_id и чистый
pathname. Первый start считается один раз на tool_id/path за загрузку страницы.
Сохранённый отказ имеет приоритет над автоматическим включением. Вебвизор и
clickmap остаются выключены.

## States

default — аналитика включена, уведомление показано; focus — видимый keyboard
focus на ссылке/кнопках; disabled — пользователь выбрал отказ и события не уходят.
Асинхронных loading/empty/error/success состояний у информационной плашки нет.

## Acceptance tests

- На первом визите без решения Метрика устанавливается ровно один раз.
- Сохранённый denied не включает Метрику; отказ после включения прекращает новые цели.
- Первые input/change/submit внутри `[data-analytics-tool]` дают один tool_started.
- Неизвестный tool_id и любые произвольные поля не попадают в цель.
- Каждый компонент, отправляющий result_completed, объявляет тот же tool_id на границе.
- Отчёт агрегирует started/completed только по известным tool_id.
- Плашка содержит заданную сноску, ссылку на политику, «Понятно» и явный отказ.
- На 320/768/1440 px нет перекрытия контента и горизонтального overflow.

## Allowed files

Перечень задан в task.json; изменения ограничены аналитическими библиотеками,
компонентом уведомления, границами существующих инструментов, тестами и этим run.

## Verification commands

`npm --prefix web run test:sites`; `npm run analytics:test`; `npm run build`;
Design Harness spec/final/ship; headless browser screenshots 320/768/1440.

## Sources and claims

Публичная сноска описывает фактическую Яндекс Метрику и ссылается на собственную
политику. Новых внешних фактических или продуктовых утверждений нет.

## Asset contract

Новых растровых/векторных assets нет. Текст exact-content проверяется тестом.
Imagegen не используется: задача касается компактного системного уведомления,
для которого существующие токены дают более точный результат.

## Review and rollback

Автоматические тесты, responsive screenshots и независимая браузерная проверка.
Rollback: один merge-коммит, возврат на предыдущий Pages artifact.
