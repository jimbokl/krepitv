# Visual Direction

## Visual Thesis

«Технический паспорт происхождения ответа»: компактно, строго, проверяемо и в существующем индустриальном языке KREPI TV.

## Direction Options

1. Четыре паспортные ячейки + раскрываемая методика.
2. Один длинный юридический абзац.
3. Отдельная боковая карточка автора.

## Selected Direction

Вариант 1: он показывает четыре решения без клика, остаётся компактным и складывается 1×4 → 2×2 → 4×1 по ширине.

## Hierarchy And Reading Order

Заголовок/ответ страницы → автор → основание → дата → физический тест → подробный способ подготовки → основной инструмент/каталог → коммерческий выход.

## Composition And Negative Space

Одна горизонтальная полоса с `gap-px`, рамкой и внутренним отступом 16 px; подробности отделены общей нижней ячейкой.

## Palette And Typography

Только существующие `paper`, `ink`, `action`, `technical`; подписи `font-mono`, значения `font-display`, основной текст стандартным sans.

## Responsive Or Sequence Behavior

320 px — одна колонка; 768 px — две; 1440 px — четыре. Native `details` растёт по высоте и не создаёт горизонтальный скролл.

## Exact-content Layer

Автор, physical-test label и заголовок подробностей рендерятся точным контролируемым текстом из JSON-контракта.

## Imagegen Layer And Invariants

None: generated image не нужен. Нельзя заменять текст декоративной картинкой или скрывать критические ограничения.
