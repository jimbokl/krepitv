# Visual Direction

Сохраняется утверждённая техническая эстетика KREPI TV: тёплый paper-фон, чёрная типографика,
оранжевое действие, зелёное подтверждение, тонкие инженерные границы. Выбор марки оформляется как
один крупный нативный select с явной подписью и кнопкой продолжения — без стены из 22 логотипов.

Иерархия: номер шага → крупный заголовок → краткое объяснение → одно обязательное действие →
TrustMark. На мобильном четыре маркера шага остаются в одну строку, подписи скрываются; на desktop
они образуют вертикальную рейку. Фокус видим через action ring, disabled-кнопка не маскируется под
активную.
