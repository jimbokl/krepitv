# Visual Direction

## Visual Thesis

Технический мастер, похожий на рабочий измерительный инструмент: один вопрос,
одна развилка, один проверяемый результат. Визуальная новизна не требуется;
доверие создаёт строгая преемственность с уже утверждённым KREPI TV.

## Direction Options

1. Строгое продолжение существующих traffic wizards — выбрано.
2. Отдельные карточки-приложения — отклонено: создаёт второй язык продукта.
3. Длинная статья с плавающим калькулятором — отклонено: результат уходит ниже.

## Selected Direction

Faithful extension утверждённого reference: orange только для действия,
technical blue для ручной проверки, green для подтверждённого результата,
danger только для настоящего stop/error.

## Hierarchy And Reading Order

H1 → короткий lead → мастер → результат → ограничения/официальные источники →
FAQ → связанные инструменты. SEO-текст не ставится перед полезным результатом.

## Composition And Negative Space

Desktop: фиксированная вводная колонка 22 rem и гибкая колонка вопросов.
Mobile/tablet: одна колонка, завершённые необязательные детали под `<details>`.
Результат отделён двойной линией, не набором декоративных карточек.

## Palette And Typography

Только существующие semantic Tailwind tokens. Display — заголовки, Sans —
инструкции, Mono — kicker/status/source date. Raw colors запрещены.

## Responsive Or Sequence Behavior

На 320 px все choice grids становятся одной колонкой, кроме коротких Да/Нет/Не
знаю. Высота только min-height. После submit focus переходит на H2 результата;
radio не перехватывает focus автоматически.

## Exact-content Layer

Все инструкции, частоты, статусы и ссылки находятся в Rust/JSON/React/SSR и
проверяются тестами. В screenshot нет единственного экземпляра важного текста.

## Imagegen Layer And Invariants

None. Новый raster не нужен; используются утверждённые reference, токены и
детерминированные CSS/SVG-паттерны.
