# Visual Direction

## Visual Thesis

Сохранить строгую техническую эстетику KREPI TV: крупный заголовок модели, три доказательства совместимости, затем короткий коммерческий блок и брендовые группы под катом.

## Direction Options

1. Существующая техническая карточка с чёткой иерархией доказательств.
2. Более товарная сетка с крупными фото; отклонена как ослабляющая собственную ценность сервиса.
3. Сверхкомпактная карточка без полного списка крепежа; отклонена как недостаточно доказательная.

## Selected Direction

Вариант 1 без визуальной переработки.

## Hierarchy And Reading Order

H1 → источник и дата → три проверки → паспорт модели → только verified-fit предложения → полный каталог под `<details>` → методика и ограничения.

## Composition And Negative Space

Одноколоночная мобильная композиция; на десктопе факты слева, результат справа. Между блоками используются существующие тонкие и толстые линии.

## Palette And Typography

Существующие paper/ink/action/technical токены и Roboto Condensed + IBM Plex. Новые цвета и размеры не добавляются.

## Responsive Or Sequence Behavior

На 320 px карточки и доказательства идут последовательно без горизонтального скролла. На 1440 px сохраняется двухколоночная структура. Длинные списки закрыты по брендам.

## Exact-content Layer

Название модели, VESA, масса, диагональ, число verified-fit и ссылки кронштейнов рендерятся детерминированно из проверенных данных.

## Imagegen Layer And Invariants

None: сгенерированные изображения не используются.
