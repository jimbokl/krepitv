# Design Specification

## Context

Мобильный PageSpeed выявил CLS 0,302 и поздний LCP. Причина подтверждена браузерным профилированием: после SSR клиент заменял весь `#root` полноценным React-приложением.

## Goal

Сохранить утверждённую визуальную систему KREPI TV и самостоятельную ценность SSR, усиливая JavaScript только интерактивные участки главной, паспорта модели и мастера подбора.

## Non-goals

Новый арт-дирекшен, новая семантика, новые URL, изменение офферов, цен или партнёрских правил.

## Inputs

Утверждённые референсы `01-homepage.png`, `02-guided-selection.png`, `03-model-page.png`; текущие Tailwind-токены; отчёт PageSpeed; существующие русские тексты и данные каталога.

## Constraints

Русский интерфейс; SSR остаётся полезным без JavaScript; нет кратковременного пустого root; CLS ≤ 0,1, LCP ≤ 2,5 с и TBT ≤ 200 мс в локальном mobile slow-4G gate; нет новых сырых цветов или новой дизайн-системы.

## States

Default/success проверяются скриншотами. Loading, empty и error должны сохранять SSR и проверяются unit-тестами fail-closed загрузчиков. Disabled и focus покрыты существующими нативными состояниями формы и тестами мастера. Визуальный layout этих состояний не перерабатывается.

## Acceptance tests

- На главной меняется только поисковый island; SSR-root не исчезает.
- На модели меняется только блок свежих предложений; паспорт остаётся в DOM.
- В `/podbor/` React монтируется во внутренний island без вложенного `<main>`.
- Главная запрашивает только `/data/model-search.json` до пользовательского действия.
- Три контрольных маршрута проходят мобильный CLS/LCP/TBT gate без полной замены root.
- 320, 768 и 1440 CSS px не создают горизонтальный overflow и сохраняют иерархию утверждённых референсов.

## Allowed files

Только перечисленные в `task.json` исходники загрузки/islands, SSR-генератор, тесты, QA-скрипт, package scripts и воспроизводимый `docs/` artifact.

## Verification commands

Команды `unit`, `performance` и `release` из `task.json` обязательны. Скриншоты дополняют, но не заменяют машинные проверки.

## Sources and claims

Единственная внешняя проверяемая исходная цифра — baseline PageSpeed из предоставленного отчёта. Визуальные решения сверяются с локальными утверждёнными референсами.

## Asset contract

Новых изображений нет. Imagegen не используется: задача сохраняет существующий дизайн и устраняет клиентскую нестабильность.

## Review and rollback

До релиза: visual regression, drift scan, полный release-gate. Откат — revert единственного коммита спринта и повторная публикация предыдущего `docs/` artifact.
