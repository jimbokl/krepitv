# Independent Review

## Reviewer

Programmatic Design Harness + headless Chromium QA.

## Verdict

PASS. Открытых замечаний P0–P2 нет.

## Причина дефекта

Скриншот текущей вкладки внешнего Chrome показал, что иллюстрация не меняла z-index и не
накладывалась на паспорт модели. Значения `dd` выходили из родительской колонки шириной 18rem:
внутренняя сетка резервировала 2.5rem под пиктограмму и фиксированные 13rem под подпись, поэтому
для значения почти не оставалось места.

## Исправление

В подробном `ModelFacts` обе текстовые колонки стали сжимаемыми через `minmax(..., 1fr)` и
`minmax(0, 1fr)`. Для контейнеров добавлен `min-w-0`, а длинным значениям разрешён перенос через
`overflow-wrap:anywhere`. На мобильной ширине значение остаётся во второй колонке под подписью,
а начиная с `sm` занимает отдельную третью колонку.

## Визуальная проверка

Проверены 320×800, 768×1024 и 1470×956 CSS px. На всех трёх ширинах паспорт читается целиком,
значения не пересекают иллюстрацию, нет горизонтального переполнения или обрезанного текста.
Ширина 1470 px соответствует рабочей области сделанного скриншота внешнего Chrome.

## Регрессионная защита

SSR-тест фиксирует адаптивный контракт подробного паспорта. Browser QA вычисляет фактические
прямоугольники `dt` и `dd` и завершает проверку ошибкой, если любой текст по горизонтали и
вертикали пересекает область иллюстрации. Все состояния `/podbor/` и обязательные viewport
проверены; состояние фокуса остаётся видимым.

## Design-system drift

Сохранены существующие Tailwind-токены, типографика, цвета, пиктограммы и порядок чтения.
Drift-скан прошёл без ошибок. Новые URL, цены, редиректы и партнёрские ссылки не добавлялись.

## Rollback

Откатить release-коммит, пересобрать `docs/` и повторно развернуть GitHub Pages. Данные,
URL и серверное состояние не менялись.
