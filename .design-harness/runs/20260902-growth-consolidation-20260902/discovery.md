# Discovery

## Existing Design System

CTA уже использует токены Tailwind `paper`, `ink`, `action`, существующую кнопку `primary-button`, техническую нумерацию шагов и responsive-сетку. SSR генерируется Rust, React гидратирует тот же смысловой блок.

## Reuse Decisions

Сохранить структуру, границы, типографику и сетку. Изменить только точность заголовка, объяснение и подпись действия. Событие привязать к существующей ссылке без нового интерактивного компонента.

## New Primitives And Rationale

None: новый визуальный примитив и графические активы не требуются.

## Risks

Длинный русский заголовок может переноситься неравномерно. SSR и React должны иметь дословно одинаковый текст. Повторные рендеры инструмента не должны завышать число завершений.
