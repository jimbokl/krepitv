# Design Specification — проект визуального движка

## Context

KREPI TV уже имеет статический SSR-контент, Rust/WASM-расчёты и отдельные SVG-инструменты. Референс SAEL показывает пользу непрерывной управляемой сцены, а пользователь отдельно подтвердил ценность выразительной графики для всех семейств инструкций.

## Goal

Реализовать повторно используемый плеер шагов, четыре сценария (монтаж, высота, розетки, HDMI) и обновлённую масштабную сцену планировщика стены. Выпустить на существующих URL.

## Non-goals

Не создавать новые URL или выдавать иллюстрацию за точную разметку. Расчёты остаются в существующем Rust/WASM-движке; анимация не заменяет проверку основания и паспорта крепления.

## Inputs

`DESIGN.md`, существующие SVG-компоненты, каталог моделей/кронштейнов, Rust/WASM-результаты, статические статьи и внешний визуальный референс SAEL.

## Constraints

Русский публичный интерфейс; проверяемые характеристики и границы точности; статический полезный HTML при выключенном JS; действующая палитра/типографика; параметры пользователя не уходят в аналитику. Эти требования уже заданы проектом, а не вводятся новым планом.

## States

Состояния: default (демонстрация), loading (расчёт), empty (пустое обязательное поле), error (ошибка WASM), success (личная схема), disabled (граница шага или недостаточно данных), focus (клавиатурная навигация), paused и reduced-motion. Без JS статья и текстовый ответ остаются доступными, интерактивная сцена — прогрессивное дополнение.

## Acceptance tests

- Первый ввод меняет визуальное состояние и одновременно текстовую подпись; пользователь может вернуться к предыдущему шагу без потери исходных параметров.
- Точные числа сцены совпадают с результатом Rust/WASM и источником каталога; для неизвестной стеновой площадки отсутствуют точные точки сверления.
- На 320/768/1440 px нет горизонтального переполнения и перекрытых полей; фокус виден, управление возможно клавиатурой. Отдельный прогон проверяет 200% текста и увеличенные межбуквенные/межсловные интервалы.
- Подписи зазоров точной схемы читаются при крайних допустимых положениях ТВ: постоянный светлый halo защищает тёмный текст от экрана и мебели. QA проверяет нижний Rust-clamp на 768/1440 px, где подпись оказывается поверх экрана.
- При reduced motion переход мгновенный, но смысл, порядок и итог не теряются.
- При загрузке, ошибке или отсутствии модели есть понятное действие восстановления.
- Первый HTML содержит ответ и ссылки без JS; анимация не становится единственным носителем инструкции.
- После реализации `npm run build` и браузерные снимки всех значимых состояний проходят без регрессии.

## Allowed files

Кодовый срез зафиксирован в `task.json`: компоненты сцены и планировщика, подключение на SEO-страницах, стиль, браузерный QA, тесты, собранные `docs/` и документы состояния. Пользовательский неотслеживаемый исследовательский файл не меняется.

## Verification commands

`git diff --check`, `npm run build`, `node scripts/qa/verify-instruction-scenes.mjs`, независимый визуальный review, drift/final/ship gates. Браузерный QA работает с production-артефактом на локальном сервере и отключённой Метрикой; после деплоя — HTTPS, redirect, sitemap и хеши HTML/JS/CSS.

## Sources and claims

Внешний референс: `https://sael.net/internet/` (управляемая сцена, шаги, what-if и раскрытие методики). Фактические размеры и совместимость в будущем брать только из проектного каталога/источников; эта спецификация не публикует новых чисел о ТВ.

## Asset contract

Responsive HTML/SVG для существующих страниц. Контрольные viewport 320×800, 768×1024, 1440×900. Текст и числа накладываются детерминированно. Imagegen для точного схемного слоя не применяется: генерируемые монтажные детали не были бы проверяемым источником данных.

## Review and rollback

Независимый reviewer сопоставляет реальные кадры, исходный код и ограничения. Откат — обратный коммит релиза, повторная сборка и Pages deploy; предыдущая рабочая точка `cfb0e668a`. Результаты фиксируются в `review.md` и `evidence.json`, затем пакет запечатывается.
