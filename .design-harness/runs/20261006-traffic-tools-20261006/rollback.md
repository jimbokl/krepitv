# Откат спринта

Откат выполняется отдельным коммитом, без сброса чужих изменений или удаления пользовательского исследовательского файла.

1. Проверить git status и текущий source commit в HANDOFF.md.
2. Откатить только исходный коммит этого спринта через git revert, вручную разрешив пересечения с последующими обновлениями каталога. Документационный evidence-коммит не содержит production-кода.
3. Выполнить npm run build и git diff --check. Проверить обе страницы и события, зафиксировать новый статический артефакт docs/.
4. Опубликовать обратное изменение через main, дождаться source CI и GitHub Pages.
5. Проверить HTTPS, sitemap, canonical, побайтовое совпадение контрольных HTML/JS/CSS/JSON и отсутствие реальных аналитических запросов тестового браузера.

На macOS локальный WASM не является побайтовым эталоном Linux CI: проверяются контракт модуля и работа опубликованного расчёта. Не использовать git reset --hard и не подменять опубликованную историю.
