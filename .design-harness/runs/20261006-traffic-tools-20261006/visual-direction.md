# Visual direction
1. Тезис: понять глазами до настройки.
2. Иерархия: формат → действие → сравнение → следующий шаг.
3. Композиция: три схемы рядом, на мобильном вертикально.
4. Палитра: существующие paper/ink/action/technical.
5. Типографика: Condensed headings, Plex Sans text, mono percentages.
6. Взаимодействие: native select, кнопка, loading/error/disabled; смена скрывает прошлый результат.
7. Графика: точный SVG с кругом и краевыми метками, геометрия Rust; без imagegen для чисел.
