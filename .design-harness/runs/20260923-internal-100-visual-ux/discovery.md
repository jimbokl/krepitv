# Discovery

`data/seo_pages.json` содержит 155 индексируемых SEO-страниц, из них 96 пошаговых руководств. На внутренних страницах есть текстовые таблицы, интерактивы и проверенные источники, но в верхней части только три страницы имели редакционные изображения. React и статический Rust HTML показывают сходное содержание, поэтому визуальные изменения нужны в обоих шаблонах.

Основная повторяющаяся проблема: заголовок и длинный лид ведут сразу к однотипным текстовым секциям; пользователь не видит «свою ситуацию» и точку входа в инструмент. Все 96 руководств уже имеют три `guide.steps`, которые можно показать в виде компактной визуальной развилки без новых технических утверждений. Дополняем их четырьмя существующими высокоинтентными инструментами: подключение телефона, отсутствие сигнала, монтажная карта, высота телевизора.

Фото — контекст, не схема. Технические решения и стоп-условия остаются живым HTML из проверенных данных. Три существующих кадра про модель, стену и высоту можно переиспользовать; остальные тематические сцены требуют восьми новых фото. Отдельные сцены для беспроводного подключения, напольной стойки и перевозки введены после независимой проверки тематического соответствия.
