# Visual Direction

## Visual Thesis

«Технический помощник, а не статья»: два ясных выбора, крупный проверяемый результат, чёрные разделители и минимум декоративных контейнеров.

## Direction Options

1. Новый карточный wizard с отдельной палитрой — отклонён: нарушает уже одобренный референс.
2. Длинная сравнительная статья с таблицей наверху — отклонена: медленнее приводит к решению.
3. Точный клон оболочки существующего калькулятора KREPI TV с прогрессивными radio — выбран.

## Selected Direction

Вариант 3. Он сохраняет доверие и дизайн сайта, но меняет предметную иерархию: устройство → телевизор → условие → инструкция.

## Hierarchy And Reading Order

Hero с прямым интентом; мастер сразу под ним; результат сразу после submit; затем краткие различия технологий, факты/FAQ и внутренние инструменты. Никакого affiliate CTA.

## Composition And Negative Space

На desktop слева фиксированное объяснение, справа вопросы; на mobile одна колонка. Чёрные 1–2 px линии формируют секции, а не вложенные карточки. Между решениями сохраняются крупные вертикальные интервалы.

## Palette And Typography

Только semantic tokens: paper/ink как основа, action для выбора, verified только для подтверждённого пути, technical для ручной проверки, danger для настоящей ошибки. Roboto Condensed — заголовки; IBM Plex Sans — шаги; IBM Plex Mono — статусы.

## Responsive Or Sequence Behavior

На 320 px одновременно виден один этап; сетки становятся колонкой, details закрывают второстепенные варианты. На 768/1440 вопросов не больше четырёх на строку. Focus остаётся на native control; после submit переходит на заголовок результата.

## Exact-content Layer

Все подписи, шаги, ограничения, числа частотности и источники хранятся в JSON/Rust/JS/SSR и рендерятся HTML. Никакого текста внутри изображений.

## Imagegen Layer And Invariants

None: утверждённый продуктовый язык уже существует, а задаче важнее точный интерактивный ответ.
