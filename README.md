# КРЕПИ ТВ

Российский независимый сервис подбора кронштейна по точной модели телевизора.
Пользователь получает проверку VESA, диагонали, массы, запаса нагрузки и
расчёт высоты установки. Основной публичный адрес —
[krepitv.ru](https://krepitv.ru/).

## Что уже работает

- главная страница с поиском модели;
- пошаговый подбор модели, основания стены и механизма;
- локальная проверка совместимости в Rust/WASM;
- 151 карточка точных моделей и 25 карточек кронштейнов с паспортными источниками;
- 133 наблюдения текущего ассортимента Маркета сохранены без подмены качества:
  73 сопоставлены с точными моделями, 7 сведены в canonical-дубли, 53
  неоднозначных карточки закрыты `noindex` без выдуманного крепежа;
- паспорта настенного монтажа для 27 популярных моделей; точные винты либо паспортные диапазоны L/C,
  обязательные детали и регион источника без догадок по соседней модели;
- отдельный бесплатный [подбор винтов VESA по точной модели](https://krepitv.ru/vinty-dlya-krepleniya-televizora/)
  с официальным источником для каждого ответа;
- бесплатный [мастер подключения телефона к телевизору](https://krepitv.ru/kak-podklyuchit-telefon-k-televizoru/)
  с консервативной локальной проверкой AirPlay, Google Cast, Smart View и
  проводного HDMI без догадок по бренду или разъёму USB-C;
- бесплатный [мастер проверки «Нет сигнала»](https://krepitv.ru/televizor-pishet-net-signala/),
  который локально разделяет HDMI, эфирную антенну, операторскую приставку и
  спутниковый приём и выдаёт одну безопасную следующую проверку;
- три бесплатных мастера диагностики наблюдаемого симптома: звук без изображения,
  отсутствие звука и неработающий пульт; ответы рассчитываются локально, используют
  официальные источники и останавливаются до догадок о неисправной детали;
- открытый версионированный [датасет винтов VESA для популярных в России моделей](datasets/ru-tv-vesa-screws/)
  в CSV и JSON без цен, остатков и партнёрских ссылок;
- поиск размера VESA по всем 151 точным моделям внутри существующего
  [калькулятора VESA](https://krepitv.ru/vesa/) и открытая
  [таблица VESA](datasets/ru-tv-vesa-sizes/) с официальным источником каждой строки;
- фиксированный [релиз размеров VESA 2.2.0](https://github.com/jimbokl/krepitv/releases/tag/datasets-v2.2.0)
  для 151 модели; отдельный [релиз паспортов винтов 1.1.0](https://github.com/jimbokl/krepitv/releases/tag/datasets-v1.1.0)
  сохраняет 27 моделей и 30 групп винтов;
- 2 439 полностью подтверждённых связей совместимости модель ↔ кронштейн и
  575 условных вариантов, которые всегда показаны отдельно;
- локальный калькулятор высоты установки;
- двусторонний калькулятор «расстояние ↔ диагональ»;
- 55 SEO-материалов; все неподтверждённые и служебные маршруты закрыты
  `noindex,follow` и исключены из sitemap;
- 237 индексируемых URL, статическая перелинковка, sitemap, robots и JSON-LD;
- проверяемые прямые предложения Яндекс Маркета только для точных совместимых
  пар, без региональных цен и без редиректов;
- consent-gated воронка
  `result_completed → mount_detail_click → market_click → APPROVED payment`
  без передачи модели, кронштейна, параметров расчёта и текста поиска;
- полностью статический production без платного сервера.

Пример точного монтажного паспорта: [TCL 65C7K — VESA 300×300, разные винты
верхнего и нижнего ряда и 15 подтверждённых кронштейнов](https://krepitv.ru/modeli/tcl-65c7k/).

## Сборка

```bash
npm --prefix web ci --no-audit --no-fund
npm run build
```

Production формируется в `docs/` для GitHub Pages. Полная команда также
запускает тесты Rust, проверку русского публичного текста, тесты статического
хостинга и проверку состава релиза.

Версии сборки закреплены в `.node-version` и `rust-toolchain.toml`:
Node.js 22.23.2, Rust 1.93.1 и `wasm-pack` 0.13.1. WASM собирается с
переназначением локальных путей и повторной проверкой SHA-256, поэтому в бинарь
не попадают каталоги конкретной машины. Отдельный CI на каждый push/PR
исходников выполняет полный build без публикации. Pages независимо повторяет
эту закреплённую сборку на Ubuntu и публикует созданный в ней `docs/`, а не
доверяет локально скомпилированному бинарнику. Текстовые, HTML, CSS и
JavaScript-артефакты должны побайтово совпасть с Git. Для WASM, который может
различаться между host-компиляторами macOS и Linux, каждая release-сборка требует
повторяемости двух сборок на одном runner и точного совпадения WASM с его
публикуемой копией в `docs/`.

Фактическая схема GitHub Pages, DNS REG.RU, автоматического TLS, проверки
production и аварийного восстановления описана в
[`product-docs/operations/hosting-tls-playbook-2026-08-13.md`](product-docs/operations/hosting-tls-playbook-2026-08-13.md).

## Данные и доверие

Модели и кронштейны лежат в `data/`. В каталог добавляются только позиции с
официальным HTTPS-источником. Совместимость рассчитывается локально и не
отправляет параметры телевизора на сервер.

Публичные датасеты собираются из той же проверенной базы. После изменения
паспортов или VESA их нужно обновить командой `npm run dataset:generate`; gate
`npm run dataset:check` не пропустит устаревшую выгрузку.

## Монетизация

Ближайший gate — минимум 1 001 легитимный уникальный посетитель в сутки семь
полных дней подряд. Только после прохождения этого порога возобновляется
оптимизация партнёрской выручки; показы, тестовые заходы, боты и неполные сутки
в gate не входят.

План — профессиональная программа дистрибуции Яндекс Маркета. Платные кампании
не запускаются: действующая политика программы прямо ограничивает контекстную
рекламу. До письменного подтверждения поддержки трафик строится только через
SEO. Исследование и прогноз Директа сохранены в
`product-docs/research/yadirect/` как данные для будущего решения.
