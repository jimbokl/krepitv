# SEO и продукт: два спринта, 29 сентября 2026

Этот снимок отделяет показ, клик, наблюдаемого посетителя и полезное завершение. День релиза 29 сентября не входит в сравнение «до/после»: полное окно после релиза 30.09–13.10 ещё не наступило.

## Спринт 1 — диагностика

- Google Search Console, завершённое окно 31.08–27.09: 2 436 показов, 53 клика. Инспекция 449 URL: 270 индексируются, 92 обнаружены без индекса, 81 неизвестен Google, 6 просканированы без индекса. У всех шести просканированных URL получение успешно, заданный и выбранный Google canonical совпадает с самим URL. Это не доказывает причину неиндексации.
- Яндекс Вебмастер, 15–28.09: 895 показов, 64 клика; снимок индекса — 154 страницы в поиске и 14 исключённых. В 13 доступных событиях удаления причина `LOW_QUALITY`: девять паспортов моделей и четыре статьи. Это классификация Яндекса, а не установленный дефект всех страниц шаблона.
- Метрика, полные дни 15–28.09: 89 наблюдаемых органических пользователей, 93 визита; 14 стартов инструментов, 0 завершений, 5 переходов на Маркет и 1 переход к карточке крепления среди всех наблюдаемых источников. Разбивка стартов по инструментам недоступна: API отвергает запрос с параметрами цели, отчёт корректно возвращает только общий итог. Нельзя приписать 14 стартов конкретному инструменту или считать 0 завершений доказательством отказа интерфейса.
- Контракт события проверен: `tool_usage` возникает при первом действии в инструменте; `result_completed` — лишь после явного полезного результата. Чек-лист приёмки отправляет только контролируемые `toolId`/`resultType`, без ответов и серийного номера. После релиза нужен реальный пострелизный срез и сценарный браузерный тест; при недостатке наблюдений причина разрыва останется неизвестной.
- В production исходный HTML шести проверенных шаблонов — главной, инструкции, руководства по монтажу, паспорта модели, карточки кронштейна и приёмки — отдаёт HTTP 200, self-canonical, H1, основной текст и обычные ссылки без выполнения WASM. Ключевой ответ не зависит от отрисовки пустого `div`. Данные консолей не показывают общего отказа загрузки у страниц с инструментами. Эквивалентность обработанного HTML глазами каждого робота отдельно не доказана.
- Аналитика в текущем коде включена по умолчанию с возможностью отказа. Долю блокировки браузерами или долю незамеченных посетителей без независимого источника не вычислить; размещённого отдельного сервера хитов у статического сайта нет. Оценку охвата в процентах не выдумываем.
- Неуспешный workflow проверки предложений 28.09 остановился на `catalog:audit-model-pages`: одна модель содержала текст-заглушку. В исходном дереве аудит прошёл; повторный workflow 29.09 завершился успешно и закрыл этот конкретный инцидент.

Новых URL и вариаций по моделям не создавали. Другие страницы с показами оставлены без правки: отсутствие кликов само по себе не доказывает дефект заголовка. Для страницы приёмки предусмотрены предостережения: автоматического юридического вердикта и гарантии исправности нет.

Локальный браузерный сценарий собранного сайта пройден с клавиатуры: шесть ответов активируют итог, изменение одного ответа сбрасывает прежний итог, повторный расчёт показывает замечание, копирование выдаёт подтверждение. Это проверка интерфейса, а не свидетельство реальных пользовательских завершений. Полный `npm run build` пройден после изменения компонента; лимит чанка сохранён за счёт ленивой загрузки чек-листа.

## Следующий замер

После завершения 13 октября и дозревания данных сравнить равные окна по `/spravochnik/`, страницам саундбара, подключения телефона и двум изменённым canonical: входы, старты, полезные завершения и следующий шаг. Google, Яндекс и Метрику не складывать. Отдельно повторить классификацию исключений по URL: у шести Google URL нет ошибки получения или canonical, а Яндекс назвал 13 примеров малоценными; причину нужно проверять по содержанию и реальному спросу, не массовой переписью шаблона.
