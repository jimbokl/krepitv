# KREPI TV — доказательный калькулятор полной длины VESA-винта

Дата решения: 31 июля 2026 года.

Статус: локальный release gate пройден; production проверяется отдельно по
фактически опубликованному commit SHA.

## Почему улучшена существующая страница

Строгий Wordstat-срез по России, за последнее доступное месячное окно, режим
«Топ запросов», все устройства, дал отдельные exact-частоты:

| Запрос | Частота |
|---|---:|
| `болты для крепления телевизора к кронштейну` | 1 030 |
| `какие болты нужны для крепления телевизора` | 511 |
| `винты для крепления телевизора к кронштейну` | 267 |

Это пересекающиеся формулировки: значения не складываются и не трактуются как
размер уникальной аудитории. Они подтверждают один и тот же практический job,
поэтому улучшен существующий canonical
`/vinty-dlya-krepleniya-televizora/`; новый URL не создан.

Нормализованный evidence находится в
`data/research/problem-intent-demand-2026-07-31.json`, исходный пакет — в
`product-docs/research/raw/wordstat-problem-intent-2026-07-31/`.

## Что реализовано

Rust/WASM-ядро вычисляет только непрерывный допустимый диапазон:

`паспортное зацепление + планка + шайбы + обязательные внешние детали`.

Ядро не округляет результат и не выбирает ближайший товарный размер. Обе
границы паспортного зацепления обязательны; перевёрнутый диапазон,
отрицательные, нечисловые и выходящие за защитный предел значения блокируются.
Контрольный пример `19–21 + 3 + 1 + 0` даёт `23–25 мм`.

В каталоге 80 моделей. Для 26 моделей сохранён паспорт винтов; у 19 из них
есть обе границы зацепления, поэтому только эти модели могут показать
калькулятор. Если руководство требует дополнительные детали, их измерение
обязательно. При разном внешнем пакете сверху и снизу расчёт повторяется для
каждой точки: один размер нельзя переносить на все винты.

Калькулятор появляется только после выбора точной модели на странице винтов.
При смене модели компонент перемонтируется по её ID, поэтому прежний результат
не может остаться на экране. Внутри калькулятора нет цены, выбора SKU и ссылки
на Маркет; сначала остаётся самостоятельный технический результат.

## Локальный release gate

- sitemap сохранил 142 indexable canonical и тот же SHA-256;
- полный Rust/WASM и web build генерирует 142 страницы;
- Rust-проверки покрывают формулу, точность и fail-closed ошибки;
- web-проверки покрывают SEO-ответ, eligibility, отсутствие Market-ссылки и
  сброс состояния при смене модели;
- mobile E2E 390×844 для Samsung QE43Q7FAAUXRU получил `23–25 мм` без
  горизонтального overflow;
- статический аудит прошёл 142 URL с максимальной глубиной 2;
- affiliate-аудит подтвердил только прямые ссылки на разрешённый host.

## Production gate

После публикации проверяются source SHA GitHub Pages, HTTPS/TLS, совпадение
локального и production sitemap, наличие нового JS/WASM export и интерактивный
маршрут до `23–25 мм` на мобильном viewport. В IndexNow отправляется только
изменённый canonical; HTTP 202 считается принятым уведомлением, а не
индексацией, трафиком или доходом.

Показы, клики и выручка этим релизом не заявляются. Доходом остаётся только
фактический `APPROVED payment` после отмен и возвратов.
