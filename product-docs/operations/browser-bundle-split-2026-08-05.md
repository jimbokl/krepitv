# KREPI TV — разбиение браузерного JavaScript по типам страниц

Дата: 5 августа 2026 года.

## Причина

Все 301 HTML-страница уже содержат самостоятельный SSR-ответ, но до этого
загружали один общий браузерный файл со всеми калькуляторами и сценариями. Его
размер в production-коммите `a4a20308` составлял 806 671 байт без сжатия и
206 922 байта при gzip. Даже карточка телевизора загружала код всех
диагностических страниц.

Первый подтверждённый Google page-level сигнал относится к
`/modeli/tcl-65c7k/`, поэтому снижение клиентской нагрузки на модельных
страницах является улучшением существующего URL, а не запуском новой
контентной когорты.

## Изменение

- `App.jsx` разделяет модули для главной, каталога, модели, наблюдаемой модели,
  кронштейна, SEO-инструментов, подбора и служебных страниц.
- `main.jsx` сначала загружает модуль, соответствующий серверному
  `data-page-kind`, и только затем включает React. До готовности модуля SSR
  остаётся в DOM; ошибка оставляет статический ответ, а не пустой экран.
- 404 остаётся полностью статической.
- URL, canonical, sitemap, русский текст, партнёрские ссылки и правила
  совместимости не меняются.

## Измеренный результат сборки

| Артефакт | До | После | Изменение |
|---|---:|---:|---:|
| Начальный JS без сжатия | 806 671 Б | 245 796 Б | −69,5% |
| Начальный JS gzip | 206 922 Б | 77 049 Б | −62,8% |
| Полный JS-граф модельной страницы gzip | 206 922 Б | 115 123 Б | −44,4% |
| Собственный чанк ModelPage gzip | общий файл | 4 678 Б | отдельный |

Это размер артефактов, а не полевой Core Web Vitals и не обещание роста
позиций. Эффект оценивается далее по реальным данным производительности,
показам, кликам и поведению.

## Защита от регрессии

Production verifier требует:

- один общий начальный module-script во всех HTML;
- начальный JS не более 300 КиБ без сжатия;
- отдельный ModelPage-чанк не более 40 КиБ;
- отдельный SeoPage-чанк не более 400 КиБ;
- загрузчик для каждого production `data-page-kind` и fail-closed поведение для
  неизвестного типа страницы.

HTTP 200, успешная сборка или уменьшение файла сами по себе не считаются
органическим посетителем, заказом или подтверждённым вознаграждением.
