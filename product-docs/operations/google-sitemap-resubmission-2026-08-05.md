# Повторная отправка sitemap в Google Search Console — 2026-08-05

## Измеренный дефект покрытия

Production и локальный `sitemap.xml` побайтово согласованы и содержат 215
канонических URL. Однако Search Console до исправления показывал последний
скачанный снимок от 31 июля только на 142 URL. Ошибок и предупреждений sitemap
не было, но новые URL не входили в обработанный Google снимок.

Полная URL Inspection по всем 215 URL дала:

- 34 страницы со статусом `PASS` и self-canonical;
- 56 страниц «Обнаружена, не проиндексирована»;
- 124 URL, ещё неизвестных Google;
- 1 страницу «Просканирована, но пока не проиндексирована»;
- 0 запретов robots, ошибок загрузки или подмен canonical у проиндексированных
  страниц.

Это доказывает задержку обнаружения/обработки, а не массовый технический запрет.

## Исправление

Добавлена команда `npm run analytics:gsc-submit-sitemap`. Она использует
официальный метод `Sitemaps: submit` Search Console API:

`PUT /webmasters/v3/sites/{siteUrl}/sitemaps/{feedpath}`

Источник: <https://developers.google.com/webmaster-tools/v1/sitemaps/submit>.

Команда:

1. принимает только owner-only credential-файл вне Git;
2. жёстко ограничена property `https://krepitv.ru/` и
   `https://krepitv.ru/sitemap.xml`;
3. проверяет точное совпадение локального и production sitemap;
4. требует подтверждённый уровень `siteOwner`;
5. получает write-scope только для явной операции отправки;
6. сохраняет обезличенный отчёт под `.private/` с правами `0600`;
7. не выводит service-account identity, OAuth, property ID или другие
   приватные идентификаторы.

Google принял отправку 5 августа с HTTP 204. Сразу после запроса состояние
sitemap — `processing`, а старое число 142 ещё сохранялось. Это подтверждает
приём операции, но не повторное скачивание, индексацию, показы или трафик.

## Поисковый и бизнес-контроль

Окно Google остаётся на 29 показах и 3 кликах. Единственная page-opportunity с
порогом 10 показов — `/modeli/tcl-65c7k/`; она уже исправлена в предыдущем
цикле, нового query→page сигнала нет. Яндекс подтверждает 123 страницы в
поиске, 0 исключённых, 3 показа и 1 клик.

Метрика за 30 июля — 4 августа: 0 подтверждённых органических пользователей,
0 `result_completed`, 0 переходов в карточки и 0 переходов на Маркет.

Поэтому в этом цикле не создаются URL и не переписывается контент. Следующая
проверка должна сначала подтвердить повторное скачивание sitemap Google и
изменение покрытия; HTTP 204 сам по себе результатом не считается.
