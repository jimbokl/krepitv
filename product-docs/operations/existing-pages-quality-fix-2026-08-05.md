# Улучшение существующих страниц — 5 августа 2026

## Результат

Улучшены существующие страницы KREPI TV без создания новых URL и без изменения фактов каталога. В sitemap остаётся 237 индексируемых URL; каталог по-прежнему содержит 151 проверенную модель телевизора и 25 кронштейнов.

## Что исправлено

- Технические статьи теперь имеют точную смысловую категорию в Rust SSR и React: подключение, диагностика, настройка, уход или расчёт.
- Поиск моделей работает с клавиатуры: ArrowUp/ArrowDown, Enter, Escape, `aria-activedescendant` и `aria-selected`.
- Для неизвестной модели первичны собственные пути сайта: проверка VESA и каталог; публичный GitHub-запрос оставлен третичным действием с предупреждением о персональных данных.
- Мобильное меню сообщает открытое состояние, закрывается Escape и возвращает фокус кнопке.
- Исправлены русские формы счётчика: например, «17 кронштейнов».
- Карточка кронштейна сразу показывает число схем VESA, подтверждённых и условных моделей. Независимый профиль остаётся раньше ссылки Маркета; полные списки, источники и техническая схема сохранены.
- Даты модели и паспорта винтов больше не выглядят как одна и та же проверка.
- Мобильные ссылки footer получили минимальную высоту цели 44 CSS px.

## Проверка

- Полный `npm run build`: Rust 149 тестов, web 203 теста, каталожные, affiliate, IndexNow и analytics проверки — без ошибок.
