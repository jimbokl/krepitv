# Traffic release: телевизор пишет «Нет сигнала»

Дата решения: 01.08.2026. Статус: pre-production verified. Публикация,
индексация и органический трафик фиксируются ниже только после отдельной проверки
production.

## Ближайшая цель

Получить **1001+ легитимного уникального посетителя в сутки семь завершённых
дней подряд**. Показы, HTTP 200, IndexNow, URL в sitemap, тестовые, внутренние и
бот-заходы посетителями не считаются. Подтверждённая серия на старте: **0/7**.
Дальняя цель после допуска площадки — 100 000 ₽ подтверждённого ежемесячного
вознаграждения Яндекс Маркета после отмен и возвратов.

## Почему выбран этот canonical

Точный Wordstat-срез по России, все устройства, `Top queries`, от 01.08.2026
зафиксировал **43 922 запроса в месяц** для формулировки
`телевизор нет сигнала`. Варианты «что делать» и «не видит HDMI» относятся к
тому же интенту и не складываются с этой цифрой. Это измеренный спрос, а не
прогноз посещений.

Выпускается один URL:
`https://krepitv.ru/televizor-pishet-net-signala/`. Страницы по брендам,
источникам, операторам и формулировкам ошибки не создаются.

## Собственная ценность

Страница не пересказывает линейную инструкцию. Rust/WASM-дерево сначала
определяет, кто показывает сообщение, затем разделяет HDMI, эфирную антенну,
операторскую приставку и спутник. Результат — одна следующая безопасная проверка,
короткая последовательность и стоп-условие. Неизвестные признаки завершаются
`unknown-source` или `needs-service`, а не вымышленным диагнозом.

- Результат рассчитывается локально, регистрации и постоянного сервера нет.
- Исходный HTML остаётся полезным без JavaScript и содержит официальные ссылки.
- На странице нет цены, Яндекс Маркета, партнёрского CTA и рекомендации покупки.
- Длинные списки исключены: пользователь видит только актуальную ветку и один план.
- Не предлагаются разборка, работа под напряжением, крыша, поворот тарелки,
  заводской сброс или покупка кабеля до сравнительной проверки.

Матрица допустимых утверждений:
`product-docs/research/TV_NO_SIGNAL_OFFICIAL_SOURCES_2026-08-01.md`.

## Контроль каннибализации

- `/televizor-pishet-net-signala/` владеет уже появившимся сообщением или
  пропавшим сигналом.
- `/kak-podklyuchit-telefon-k-televizoru/` владеет первоначальным подключением
  телефона, когда рабочего сигнала ещё не было.
- Будущая страница настройки цифровых каналов будет владеть первичным поиском
  каналов, а не внезапным исчезновением ранее работавшего сигнала.

## Release gate

1. Rust-матрица покрывает `success`, `unknown-source`, `needs-service`,
   `provider-path` и спутниковый safety stop.
2. SSR содержит один H1, один canonical, четыре первичные ветки и официальные
   источники; Market/affiliate-разметка отсутствует.
3. React сохраняет выбор при loading/error/retry, не читает query и отправляет
   только обезличенный `result_completed`.
4. На 320×800, 768×1024 и 1440×900 нет переполнения, обрезки и перекрытия;
   keyboard focus видим, 200% текста не ломает работу.
5. Полная сборка, release-аудиты, design drift и независимое ревью проходят.
6. Production-хеши HTML, sitemap, JS и WASM совпадают с локальным артефактом.

## Фактический выпуск

До production-релиза подтверждено:

- полная сборка: 66 тестов Rust engine, 31 тест sitegen и полный web/affiliate/
  analytics gate;
- 146 индексируемых HTML и 146 URL в sitemap, новый canonical встречается один
  раз и имеет `lastmod=2026-08-01`;
- security, static SEO и affiliate artifact audits прошли;
- 13 состояний сняты на 320×800, 768×1024 и 1440×900 без overflow;
- независимое ревью: PASS, P0=0, P1=0;
- общая спутниковая ветка не наследует брендовый источник Триколора, а результат
  не получает двойное объявление через focus и `aria-live`.

Коммит, GitHub Actions run, production-хеши и отправка нового URL поисковикам
заполняются после успешного production-релиза. Технические проверки до этого не
называются публикацией, индексацией или трафиком.

## Измерение

Ежедневно фиксируются завершённые сутки: реальные внешние пользователи по
источникам, поисковые посадочные, запросы, показы, клики и обезличенный
`result_completed`. Метрика среди согласившихся — нижняя граница, а не полный
счёт трафика. Следующая правка canonical допускается по query→page сигналу, а не
по одному показу.

## Rollback

При ошибке WASM, неверном canonical, опасном совете, Market-ссылке или поломке
соседнего интента откатывается один release-коммит через `git revert`. Из sitemap
удаляется только новый URL; данные моделей, предложения, аналитика и DNS не
изменяются.
