# Целостность карточек моделей и брендовые шарды офферов — 2026-08-05

## Итог

- В исходной выборке Яндекс Маркета сохранены все **133 наблюдения**.
- Они разрешаются в **53 проверенных маршрута**, **73 наблюдаемых канонических
  маршрута** и **7 alias-маршрутов**.
- Рабочий каталог содержит **131 точную модель телевизора** из официальных
  источников. У каждой есть минимум два ребра `verified-fit`; всего таких рёбер
  **2046**.
- Проверенный подбор строится только при одновременном совпадении точной пары
  VESA, паспортного диапазона диагонали и нагрузки с запасом не менее 25% к
  опубликованной массе.
- Для 18 моделей источник публикует массу с подставкой либо не уточняет её
  основание. Такая масса явно маркируется и используется консервативно; она не
  выдаётся за массу корпуса без подставки.

## Почему не у всех 133 наблюдений показан крепёж

Наблюдение Маркета не равно подтверждённой модели. В выборке есть сокращённые
названия, дубли, generic-карточки и модели, для которых производитель не
публикует одновременно VESA и массу. Для таких записей создана самостоятельная
страница проверки: идентичность, источник наблюдения, инструкция по ручной
проверке VESA и массы, ссылки на методику. Страница имеет `noindex,follow`, не
содержит партнёрского CTA и не называет ни один кронштейн «подходящим».

Это не заглушка, а fail-closed результат. Подставить крепёж только по диагонали
было бы технически неверно и небезопасно.

Отдельно отклонена `Tuvio TM85UFBCH51`: два официальных источника расходятся по
массе (41,6 и 41,0 кг). До разрешения конфликта её маршрут остаётся страницей
проверки без автоматической рекомендации.

## Автоматические барьеры

Сборка завершается ошибкой, если:

1. хотя бы одна точная модель не имеет `verified-fit`;
2. VESA телевизора отсутствует в явном списке VESA кронштейна;
3. диагональ выходит за паспортный диапазон кронштейна;
4. нагрузка кронштейна меньше массы телевизора × 1,25;
5. карточка точной модели короче 7 500 байт или содержит меньше пяти секций;
6. наблюдаемая/alias-карточка короче 6 000 байт, содержит меньше четырёх секций,
   индексируется либо показывает партнёрский CTA;
7. не найден маршрут хотя бы для одного из 133 наблюдений Маркета.

Контрольная сборка проверяет 301 HTML-страницу, 131 модель, 23 кронштейна, 2386
рёбер полного графа и 215 индексируемых URL.

## Загрузка модельных предложений

Полный публичный снимок содержит 238 актуальных модельных размещений и весит
422 932 байта (67 328 байт gzip). Runtime теперь загружает только шард бренда
открытой модели: 17 файлов, самый большой `samsung.json` — 144 542 байта
(23 567 байт gzip). Любой неизвестный или небезопасный ключ отклоняется до
сетевого запроса.

CI сверяет каждый шард с полным аудируемым снимком, проверяет отсутствие потерь
и дублей и ограничивает размер отдельного файла 150 КиБ.
