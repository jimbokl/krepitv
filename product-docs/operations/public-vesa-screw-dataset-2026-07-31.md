# Открытый датасет винтов VESA и устранение тупика поиска

Дата: 31 июля 2026 года

Статус: release candidate прошёл локальные gates, публикация через GitHub Pages

## Почему это делаем

Сохранённый Wordstat подтверждает отдельный пользовательский интент:

- «винты для крепления телевизора» — 1 095;
- «какие болты нужны для крепления телевизора» — 511;
- «винты для крепления телевизора к кронштейну» — 419.

Частотности пересекаются, поэтому их нельзя складывать. Контрольный поиск
показал официальный контент брендов, разовые ответы DNS, универсальные наборы
и общие статьи, но не обнаружил русскоязычный кросс-брендовый путь
«точная модель → винты → официальный источник → совместимые кронштейны».
Прямой Яндекс упёрся в SmartCaptcha, Google вернул redirect-shell, поэтому
порядок результатов не выдаётся за достоверный top поисковиков.

## Что изменено

- Поиск винтов теперь распознаёт все 80 известных моделей, а не только 26
  моделей с паспортом винтов.
- Для 26 подтверждённых моделей результат остаётся fail-closed: резьба,
  количество, точная длина либо диапазон зацепления, вставки и источник.
- Для остальных 54 моделей сервис честно сообщает, что паспорт винтов не
  подтверждён, не угадывает M6/M8 по VESA и ведёт в существующую карточку
  модели с совместимыми кронштейнами.
- Над поиском явно разделены винты телевизор → VESA-пластина, анкеры в стену
  и винты ножек.
- Заголовок и сниппет страницы отвечают на интент «размер по модели», а поиск
  на мобильном поставлен раньше повторяющегося блока общих фактов.

## Публичный датасет

Каталог `datasets/ru-tv-vesa-screws/` содержит версию `v1` в CSV и JSON:

- 26 точных моделей;
- 3 бренда;
- 29 групп винтов;
- VESA, резьба, тип измерения, длина либо диапазон, количество;
- статус адаптеров, обязательные детали и конфликты источников;
- реальный регион, дата проверки и официальный HTTPS-источник.

В выгрузке нет цен, остатков, партнёрских URL, reward, идентификаторов заказов
или неподтверждённых паспортов 54 моделей. Генератор детерминированный;
`npm run dataset:check` включён в общий release gate и блокирует устаревшую
выгрузку после изменения основной базы.

## Проверки

- чистая полная сборка `npm run build` — пройдена;
- 37 Rust engine + 20 Rust sitegen + 84 web + 10 catalog + 68 affiliate +
  10 IndexNow + 6 analytics тестов — пройдены;
- dataset gate — 26 моделей и 29 строк, пройден;
- русский публичный интерфейс — пройден;
- production artifact: 143 HTML-файла, sitemap остаётся на 142 URL;
- сырой HTML до запуска JavaScript содержит поиск по 80 моделям, fail-closed
  объяснение, ссылку на датасет и ставит инструмент раньше «Что проверить»;
- визуальный QA 390 px и 1 440 px — горизонтального переполнения нет;
- длинные списки 26 паспортов остаются под `details` по брендам;
- техническая страница не содержит ссылок Яндекс Маркета или цен.

## Что считается результатом

Новый GitHub-файл, push, HTTP 200, IndexNow или включение URL в sitemap не
считаются трафиком или деньгами. Финансовый baseline не изменён:
0 подтверждённых заказов и 0 ₽ APPROVED reward. Следующий gate — фактический
поисковый показ/клик, затем `result_completed`, `mount_detail_click`,
`market_click`, заказ и только после отмен/возвратов APPROVED reward.
