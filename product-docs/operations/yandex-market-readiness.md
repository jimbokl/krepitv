# KREPI TV — готовность к монетизации Яндекс Маркета

Последняя проверка: **30 июля 2026 года**.

## Текущий внешний статус

- Рублёвая схема Реферальной программы активна: кабинет предлагает вывод
  рублей без месячного лимита, а раздел счёта для выплат доступен и заполнен.
  Платёжные реквизиты намеренно не сохраняются в репозитории.
- Подтверждённое вознаграждение: **0 ₽**; сумма «в пути»: **0 ₽**.
- В разделе «Блоги» нет ни одной площадки. У `krepitv.ru` пока отсутствуют
  одобренный `place_id` и CLID, поэтому публичные партнёрские ссылки запрещены
  внутренним fail-closed gate.
- Форма добавления площадки поддерживает тип «Другое» и URL формата
  `https://...`; для подтверждения владения показывает код `YMReferral`.
- Подавать сайт сейчас нельзя: строгий HTTPS ещё не работает из-за ожидающего
  сертификата GitHub Pages. Модерация прямо проверяет, открывается ли площадка.

  https://yandex.ru/support/market-distr/ru/terms

## Безопасная последовательность запуска

1. Дождаться сертификата с `krepitv.ru` в SAN и включить Enforce HTTPS.
2. Проверить строгий HTTPS, canonical, robots и sitemap без `--insecure`.
3. Добавить на публичную страницу подтверждающий код `YMReferral` так, чтобы он
   был виден модератору, но не выглядел рекламным блоком.
4. В кабинете добавить `https://krepitv.ru` как тип «Другое», отправить на
   модерацию и дождаться явного статуса «Одобрена».
5. Получить `place_id`/CLID и OAuth-ключ; хранить ключ только в GitHub Secret или
   локальном `.private`, никогда не в исходниках и статическом артефакте.
6. Зарегистрировать креативы, получить ERID и только после этого сформировать
   прямые ссылки API для точных карточек телевизоров и кронштейнов.
7. Публиковать CTA лишь когда одновременно проходят identity, stock, reward,
   freshness, place и marking gates. При любом сбое карточка остаётся полезной,
   а рекламная кнопка скрывается.
8. Считать доходом только подтверждённое вознаграждение после отмен и возвратов;
   клики, заказы «в пути» и рекламные обещания выручкой не считать.

## Измеримый путь к 100 000 ₽

Фиксировать еженедельно:

1. уникальные органические посетители;
2. переходы на Маркет по `VID`, привязанному к странице и товару;
3. оформленные, доставленные, отменённые и возвращённые заказы;
4. подтверждённое вознаграждение и фактическое среднее на заказ;
5. доход на 1 000 органических посетителей.

План продаж нельзя строить на витринной сумме награды. После первых 30
подтверждённых заказов прогноз считается по фактическому среднему после возвратов:

```text
нужные подтверждённые заказы = 100 000 ₽ / среднее вознаграждение за заказ
нужный органический трафик = нужные заказы / фактическая конверсия посетитель → подтверждённый заказ
```

До появления этих данных продуктовый KPI — не число сгенерированных страниц, а
первые индексируемые входы по точным моделям и первый подтверждённый заказ.
