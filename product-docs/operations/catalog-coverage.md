# Контроль полноты каталога KREPI TV

Источник истины: `data/catalog-coverage.json`.

Каталог сейчас имеет статус `growing`: подготовлены 34 проверенные модели,
4 бренда, 19 серий, диагонали 32/43/50/55/65 дюймов и модельные годы
2024/2025/2026. Для них подготовлены 17 проверенных кронштейнов и 427 полезных
рёбер совместимости. Это всё ещё не полный каталог популярных телевизоров.

## Что считается полным каталогом

Популярность подтверждается отдельным снимком российского спроса по точным
моделям: `data/research/tv-model-demand.json`. 30 июля 2026 года батч из
40 SKU/точных поколений проверен для России, всех устройств и последних
30 дней комбинацией кавычек и квадратных скобок. Ненулевой спрос обнаружен у
32 моделей; все они
есть в каталоге, поэтому покрытие текущего измеренного списка равно 100%.

Восемь точных кодов Яндекс ТВ дали нулевую частоту. Семейные запросы у этих
телевизоров есть, но они намеренно не размножены по SKU и не включены в точный
рейтинг. Частотность Wordstat не считается показами, кликами, CPC или продажами.

Технический gate не позволяет снизить минимумы ниже:

- 50 проверенных моделей из demand-ranked target list;
- 5 брендов и 10 серий;
- диагонали 32, 43, 50, 55, 65 и 75 дюймов;
- модельные годы 2024, 2025 и 2026;
- 100% точных моделей из зафиксированного target list присутствуют в каталоге.

Это минимальный антидемо-порог, а не утверждение, что ровно 50 SKU исчерпывают
рынок. Полный публичный claim разрешается только если одновременно выполнены
все измеримые условия и manifest переведён в `catalog_status: complete`.

Текущие блокеры полного claim:

- 34 из минимальных 50 проверенных моделей;
- 4 из 5 брендов;
- нет диагонали 75 дюймов;
- 32 из 50 demand-ranked моделей.

Для кронштейнов действует отдельный консервативный реестр
`data/research/verified-mounts.json`. ONKRON M4, ONKRON NP40 и Holder LCDS-5003
не опубликованы из-за противоречий внутри официальных характеристик. Диапазоны
VESA никогда не разворачиваются в несуществующие пары: в расчёт попадает только
явно подтверждённый список.

## Проверка

```bash
npm run catalog:sync
npm run catalog:verify
npm run catalog:test
```

`catalog:sync` детерминированно строит рабочие `data/tv_models.json`,
`data/mounts.json` и coverage manifest из проверенных реестров. Verifier затем
сверяет manifest с каталогом один к одному. Для каждой опубликованной модели
обязательны бренд, серия, диагональ, модельный год, официальный источник
измерений и дата проверки. Снижение порогов, пропуск модели, неразрешённый
источник или попытка включить полный claim при незакрытых условиях останавливает
сборку.
