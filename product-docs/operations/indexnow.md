# KREPI TV — IndexNow

IndexNow используется только для новых, содержательно изменённых или удалённых
индексируемых URL. Он не заменяет sitemap и не гарантирует индексацию.

## Безопасный запуск

1. Записать изменённые страницы в `data/indexnow/changed-urls.txt`. Для всей
   проверенной группы допустимы директивы `@models` и `@mounts`.
2. Не включать `noindex`, параметры URL, внешние домены и страницы, где
   поменялся только хеш JS/CSS.
3. Выполнить сухую проверку:

   ```bash
   npm run indexnow:submit -- --dry-run
   ```

4. После публикации и проверки production выполнить:

   ```bash
   npm run indexnow:submit
   ```

Клиент сначала проверяет каждый URL по production sitemap, затем сверяет
публичный key-файл и отправляет один JSON-пакет в официальный endpoint Яндекса.
HTTP 200/202 фиксируется только как принятый
сигнал об изменениях — не как обход, индексирование, трафик или доход.

Публичный ключ IndexNow не является OAuth-токеном или секретом: по протоколу он
должен лежать в корне подтверждаемого сайта. OAuth Яндекс Маркета и другие
приватные данные в этом flow не используются.
