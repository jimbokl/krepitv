Дата фиксации: 31 июля 2026 года.

## Зачем она нужна

До появления зрелых данных сайт не расширяет индексируемую матрицу без
отдельного доказанного интента. Текущий sitemap содержит 142 URL. Эта когорта
связывает существующие посадочные с первой
полезной работой пользователя, переходом на Маркет и подтверждённым
вознаграждением. Один HTTP 200, отправка sitemap или IndexNow не считаются
результатом.

## Еженедельный срез

Сравниваются 7 полных дней с предыдущими 7 и 28 полных дней с предыдущими 28.
Для каждого URL используются только состояния `true`, `false`, `unknown` и
`not_matured`; отсутствие данных не заменяется нулём.

| Ступень | Источник | Начальный статус |
|---|---|---|
| URL проиндексирован | Search Console и Яндекс Вебмастер по отдельности | `unknown` до свежей проверки конкретного URL |
| Показы и клики query→page | панели поисковиков | `not_matured` |
| Полезный результат | consent-gated цель Метрики `result_completed` | `not_matured` до выпуска события |
| Переход на Маркет | цель Метрики `market_click` | `not_matured` |
| Созданный заказ | API партнёрской программы по VID | `false` на 31.07.2026 |
| Подтверждённый заказ | статус `APPROVED` после отмен и возвратов | `false` на 31.07.2026 |
| Подтверждённое вознаграждение | сумма `payment` только у `APPROVED` | 0 ₽ из 100 000 ₽ в месяц |

События Метрики наблюдаемы только среди посетителей, которые разрешили
аналитику. Поэтому их нельзя делить на все органические визиты или все заказы
без отдельного показателя покрытия согласиями.

## Gate следующей SEO-волны

Новые индексируемые страницы допускаются только после одного из двух сигналов:

1. У зрелой когорты появился устойчивый query→page-кластер с совпадающим
   намерением и не менее 10 показов на запрос или страницу.
2. Найден отдельный интент, для которого есть официальный источник, отличный
   полезный результат, совместимые товары и живое размещение Маркета.

Если через 4–8 недель после фактической индексации когорта не получает целевых
показов, сначала проверяются intent, каннибализация и самостоятельная ценность;
массовая генерация новых карточек не запускается.
