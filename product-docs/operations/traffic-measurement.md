# KREPI TV — измерение трафика и переходов

Дата фиксации: 30 июля 2026 года.

## Текущее состояние

- Счётчик Яндекс Метрики ещё не создан: форма требует явного принятия
  Пользовательского соглашения владельцем аккаунта.
- В `web/src/lib/metrikaConfig.mjs` идентификатор равен `null`. При таком
  значении production не загружает `mc.yandex.ru`, не ставит обработчики и не
  отправляет события.
- Код подключения и цель `market_click` уже подготовлены и покрыты тестами.
  Вебвизор и карта кликов намеренно выключены; событие содержит только
  технические идентификаторы карточки, страницы и VID, без пользовательских
  данных.

## Активация после согласия владельца

1. Создать отдельный счётчик для `krepitv.ru` в Метрике.
2. В настройках цели добавить JavaScript-событие `market_click`.
3. Записать публичный числовой ID в `YANDEX_METRIKA_COUNTER_ID`.
4. Обновить политику конфиденциальности до публикации активного счётчика.
5. Собрать сайт, проверить отсутствие ошибок и один тестовый `reachGoal`, затем
   исключить тестовый визит из продуктовых отчётов.

Официальная документация:

- <https://yandex.ru/support/metrica/ru/general/creating-counter>
- <https://yandex.ru/support/metrica/ru/objects/reachgoal>

## Воронка

Органический вход считается только по источнику поисковой системы. Исходящий
клик считается по `market_click`. Заказы и выплаты берутся из партнёрского
кабинета/API по тому же стабильному VID.

```text
organic_sessions → market_click → created_order → APPROVED order → payment
```

Показы, прямые и тестовые визиты, клики без заказа, `NEW`, `ON_HOLD`,
`CANCELLED`, обещанная награда и сумма корзины не являются подтверждённым
вознаграждением.
