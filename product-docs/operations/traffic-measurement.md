# KREPI TV — измерение трафика и переходов

Дата фиксации: 31 июля 2026 года.

## Текущее состояние

- Создан отдельный счётчик Яндекс Метрики `111176777` для `krepitv.ru`.
- Вебвизор и карты отключены. Метрика загружается только после явного выбора
  посетителя «Разрешить аналитику»; отказ сохраняется локально и не загружает
  `mc.yandex.ru`.
- Код подключения покрыт тестами. Цель «Переход на Яндекс Маркет» создана в
  Метрике с точным идентификатором `market_click`; тестовый сигнал endpoint
  принял 30 июля 2026 года. Вебвизор и карта кликов намеренно выключены;
  событие содержит только технические идентификаторы карточки, страницы и VID,
  без пользовательских данных.

## Активация и проверка

1. Исключить прямой визит с `metrika-test=1` и тестовый `reachGoal` из
   продуктовых отчётов.
2. Не считать текущий товарный VID достаточной атрибуцией страницы: один и тот
   же оффер переиспользуется на карточках моделей, кронштейнов и SEO-хабах.
3. До первого реального трафика выпускать VID на уровне
   `landing × offer × rank`, сохраняя приватное соответствие размещению.
4. Получать read-only `GET /orders` ежедневно и сохранять только технические
   поля заказа: хеш идентификатора, даты создания и изменения, статус, VID и
   `payment`. Исходные снимки и OAuth не публиковать.

## Воронка

Органический вход считается только по источнику поисковой системы. Исходящий
клик `market_click` наблюдается только у посетителей, разрешивших Метрику;
поэтому его нельзя без показателя покрытия делить на все заказы API. Заказы и
выплаты берутся из партнёрского API по уникальному VID размещения.

```text
organic_sessions → market_click → created_order → APPROVED order → payment
```

Показы, прямые и тестовые визиты, клики без заказа, `NEW`, `ON_HOLD`,
`CANCELLED`, обещанная награда и сумма корзины не являются подтверждённым
вознаграждением.

## Обязательные отчёты

- Ежедневный приватный реестр: новые и изменившиеся заказы, возраст незакрытых
  статусов и сумма `payment` только для `APPROVED`.
- Недельная зрелая когорта по `landing × placement × VID`: органические
  сессии, наблюдаемые клики, созданные и финальные заказы, доля подтверждения,
  средний `APPROVED payment` и подтверждённый доход на органическую сессию.
- Месячный goal ledger: сумма `payment` заказов, ставших `APPROVED` в месяце,
  против цели 100 000 ₽. Текущее подтверждённое значение — **0 ₽**.
- Заказы текущей недели не делятся на клики той же недели: учитываются
  семидневная атрибуция, получение заказа и возвратное окно.
