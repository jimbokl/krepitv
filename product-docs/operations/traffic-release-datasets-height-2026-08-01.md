# Трафиковый релиз: открытые датасеты и расчёт высоты

Дата: 1 августа 2026 года.

Основная цель релиза — рост подтверждённого органического трафика к порогу
более 1 000 пользователей в сутки. Релиз не считается трафиком, индексацией
или прохождением модерации сам по себе.

## Что изменено

- `/vesa/` и `/vinty-dlya-krepleniya-televizora/` описывают два разных
  открытых датасета и дают прямое скачивание фиксированных CSV/JSON версии
  1.0.0 с неизменяемой лицензией MIT.
- На обеих страницах добавлен отдельный `Dataset` JSON-LD с двумя
  `DataDownload`. Разметка не содержит партнёрских ссылок, параметров запроса,
  цен или неподтверждённых свойств.
- Существующая страница `/na-kakoy-vysote-veshat-televizor/` усилена внутри
  одного canonical URL под измеренный спрос: сценарии гостиной, спальни и
  кухни, расчётная таблица по диагоналям с явными допущениями и печатный
  результат калькулятора.
- Sitemap после сборки остаётся на 142 индексируемых URL; только две страницы
  датасетов и страница высоты получают `lastmod` 2026-08-01 вместо массового
  обновления дат.

Страница 32″ остаётся `noindex`: её спрос подтверждён, но текущие две точные
модели не проходят защитный порог четырёх моделей. Порог не снижен ради
публикации страницы.

## Измерение результата

Результат оценивается только по реальным поисковым пользователям в Метрике и
по кликам из поисковых кабинетов. IndexNow, очередь переобхода, HTTP 200,
скачивание релиза владельцем и тестовые визиты не являются прогрессом к цели.
