# Проверка схемы высоты

Дата: 31 июля 2026 года.

Снимки сделаны отдельным headless Chrome из локального production-артефакта
после реального запуска Rust/WASM-калькулятора с исходными значениями формы:

- `mobile-390x844.png` — мобильный viewport 390×844;
- `desktop-1440x1000.png` — desktop viewport 1440×1000.

В обоих viewport подтверждены: готовый результат, доступная SVG-схема,
отсутствие горизонтального overflow, отсутствие ссылок на Маркет внутри
результата и наличие следующего шага к монтажной карте и точной модели.

Визуальная проверка: сохранены утверждённые гарнитуры, бумажный фон, чёрная
рамка, технические цвета и прямоугольная геометрия интерфейса. На мобильном
экране подписи не выходят за SVG; на desktop контрольные линии и значения не
перекрываются.
