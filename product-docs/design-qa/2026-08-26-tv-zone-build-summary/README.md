# Проверка результата «Сборка ТВ-зоны»

Дата проверки: 26 августа 2026 года. Проверяемая страница: `/podbor/?model=tcl-55c6k`.

## Что проверено

- мобильный экран 390 px, состояние `needs-measurement`: результата достаточно для следующего ручного замера, ссылок Маркета нет;
- desktop 1440 px, состояние `verified`: связка ТВ–кронштейн показана один раз, видна одна прямая ссылка на точное предложение Маркета;
- печать 1440 px, состояние `conflict`: предупреждение и измерения сохраняются, коммерческих ссылок нет;
- во всех трёх снимках ширина документа совпадает с шириной viewport, наложений и обрезанного текста не обнаружено;
- состояния `verified`, `needs-measurement` и `conflict` получены реальным локальным Rust/WASM-расчётом без сетевых моков.

## Воспроизводимость

Снимки создаются `scripts/qa/capture-page.mjs` с состояниями `cable-verified`, `cable-needs-check` и `cable-blocked`; печатный вариант использует `--media print`. Исходные PNG лежат рядом с этим документом.

Новых индексируемых URL не создано; sitemap остаётся на 299 канонических URL.

## Безопасный откат

Откат выполняется одним revert финального feature-коммита. Он возвращает прежний результат мастера, web-адаптер и Rust/WASM-контракт одновременно; частичный откат только UI запрещён, потому что может нарушить fail-closed семантику.
