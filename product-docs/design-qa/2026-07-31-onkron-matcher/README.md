# Проверка подбора ONKRON

Дата: 31 июля 2026 года.

Снимки сделаны отдельным headless Chrome из локального production-артефакта; внешний пользовательский Chrome не использовался.

- `mobile-390x844.png` и `desktop-1440x1000.png` фиксируют первый экран страницы.
- `mobile-result-390x844.png` и `desktop-result-1440x1000.png` фиксируют реальный результат Rust/WASM для `LG OLED55C4RLA`.

В обоих viewport подтверждены точный выбор модели, 4 совместимых ONKRON, три карточки в первом экране результата, объяснения через VESA и нагрузку, закрытый блок двух неподходящих моделей, отсутствие прямых ссылок на Маркет внутри подбора и отсутствие горизонтального overflow. Результат сначала ведёт в собственные технические карточки KREPI TV.

Визуально сохранены утверждённые бумажный фон, чёрная рамка, оранжевый action-цвет, синий технический акцент, прямоугольная геометрия и исходные гарнитуры. На мобильном ввод и CTA складываются в одну колонку без обрезки; на desktop три результата читаются без горизонтальной прокрутки.
