# Visual QA: VESA и розетки за телевизором

Дата: 31 июля 2026 года.

Проверена финальная локальная production-сборка в изолированном headless Chrome.
Внешний пользовательский Chrome и его профиль не использовались.

## Результат

- viewport 390×844: `scrollWidth=390`, горизонтального overflow нет;
- viewport 1440×1000: `scrollWidth=1440`, горизонтального overflow нет;
- console/page errors: 0;
- интерфейс и видимые статусы на русском языке;
- числовые региональные цены и прямые CTA Яндекс Маркета на двух технических
  страницах отсутствуют;
- `/vesa/`: поиск по модели расположен раньше ручного сравнения, таблица
  сгруппирована по брендам, конфликт Hisense 55U7S PRO останавливает автоподбор;
- `/rozetki-pod-televizor-na-stene/`: SVG-схема, конфликт, направление сдвига
  и три внутренних перехода к проверенным карточкам отрисовываются корректно.

Скриншоты `03` показывают результат поиска VESA, `04` — масштабную схему,
`05` — продолжение с тремя кронштейнами, `06` — fail-closed конфликт
официальных источников. Для каждого состояния сохранены mobile и desktop
варианты.
