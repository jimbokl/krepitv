# Три бытовых кадра для понятной монтажной инструкции

Сгенерировано встроенным `imagegen` 23.09.2026. Исходники в этой папке;
оптимизированные WebP для сайта находятся в `web/public/assets/images/home-step-*.webp`.

Серия показывает одного обычного мужчину в современной российской квартире,
без этнических и фольклорных клише. Это редакционные иллюстрации, а не
фотодоказательство совместимости или точная схема монтажа.

| Исходник | Сюжет промпта | Где используется |
|---|---|---|
| `model.png` | Мужчина ищет заводскую наклейку на задней стороне ТВ; маркировка неразборчива, без выдуманных характеристик. | Главная, поиск модели |
| `wall.png` | Тот же мужчина проверяет стену бытовым детектором до сверления; нет разметки отверстий. | Главная, выбор крепежа |
| `height.png` | Тот же мужчина примеряет будущую высоту экрана рулеткой; нет точки сверления и числовых рекомендаций. | Главная, монтажная карта |

Общие ограничения промптов: фотореалистичный документальный кадр 3:2,
естественный свет, повседневная одежда, реальные квартирные детали, без
логотипов, надписей, водяных знаков, рекламного глянца и ложных технических
данных. Текст страницы обязан пояснять, что скрытую проводку, материал стены,
отверстия и совместимость проверяют отдельно по точным данным и инструкциям.
