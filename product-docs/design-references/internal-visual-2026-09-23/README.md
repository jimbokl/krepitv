# Визуальный пул внутренних страниц · 24.09.2026

Восемь исходных PNG создано встроенным imagegen для KREPI TV, затем механически сжато в WebP 960×640 (`cwebp -q 76 -resize 960 640`). В рабочий сайт входят только WebP; PNG оставлены как исходники дизайна.

| Файл | Сцена | Применение |
| --- | --- | --- |
| `connection.png` | Человек сверяет кабель и разъёмы ТВ | Подключения и внешние устройства |
| `wireless.png` | Человек подключает телефон к ТВ без кабеля | Беспроводные подключения |
| `diagnostics.png` | Человек проверяет ТВ с пульта | Первичная диагностика |
| `settings.png` | Человек настраивает ТВ с пульта | Меню и программные настройки |
| `display.png` | Человек осматривает экран | Изображение и экран |
| `inspection.png` | Человек осматривает новую покупку | Проверка покупки |
| `stand.png` | Человек проверяет ТВ на мобильной стойке | Напольная стойка |
| `transport.png` | Два человека готовят ТВ в упаковке | Перевозка |

Общее задание: реалистичная бытовая фотография современной обычной российской квартиры, мужчина без карикатурных этнических признаков, естественный дневной свет и нейтральная палитра. Не показывать бренды, текст, интерфейсы, логотипы и точные технические указания. Изображения не являются подтверждением порта, неисправности, размеров или типа крепежа. В `data/internal_visual_pages.json` находятся темы, alt, ограничения и точный список 100 существующих страниц. Три кадра `home-step-*` переиспользованы для близких тем модели, стены и высоты.
