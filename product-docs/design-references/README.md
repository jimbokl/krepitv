# Визуальные источники KREPI TV

Все три изображения созданы встроенным imagegen 30 июля 2026 года и являются
источниками правды для реализации:

- `01-homepage.png` — главная;
- `02-guided-selection.png` — мастер подбора;
- `03-model-page.png` — карточка модели.

Отдельные продуктовые изображения для интерфейса:

- `../generated-assets/mount-wall-system.png` — цепочка телевизор → VESA →
  кронштейн → анкер → основание стены;
- `../generated-assets/mount-mechanisms.png` — фиксированный, наклонный и
  поворотный механизмы на белом фоне.

При реализации сохраняются композиция, плотность, типографическая иерархия,
цветовые роли и русский язык. Изображения интерфейсов не используются как
фоновые скриншоты: интерфейс собирается настоящими компонентами Tailwind.
