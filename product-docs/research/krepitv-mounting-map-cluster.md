# KREPI TV — кластер «монтажная карта ТВ-зоны»

Дата решения: **30 июля 2026 года**.

## Решение

Следующая индексируемая страница:
`/kak-povesit-televizor-na-stenu/`.

Это не пересказ общей инструкции. Самостоятельная ценность первой версии —
локальный Rust/WASM-расчёт пяти контрольных высот от чистого пола:

1. нижний край экрана;
2. центр экрана;
3. верхний край экрана;
4. центр VESA;
5. контрольная линия настенной пластины.

После расчёта пользователь получает последовательность переноса разметки и
печатную монтажную карту. Регистрация, сервер и переход в магазин не нужны.

## Граница первой версии

Первая версия намеренно не рисует «точную схему стены» и не выдаёт координаты
отверстий. Для этого нужны проверенные размеры пластины конкретного кронштейна.
Вместо выдуманной точности инструмент принимает два измеряемых смещения:

- центр VESA относительно геометрического центра экрана;
- контрольная линия пластины относительно центра VESA.

Знак описан прямо в форме. Диапазоны и конечность значений проверяет Rust.

Инструмент не подтверждает:

- несущую способность и состояние основания;
- тип, число или диаметр анкеров;
- отсутствие скрытой проводки и труб;
- безопасность сверления и электромонтажа;
- координаты отверстий без штатного шаблона;
- отсутствие всех механических коллизий;
- соответствие расчётной области 16:9 фактической рамке корпуса.

## Следующие URL — только после собственной функции

1. `/rozetki-pod-televizor-na-stene/` — контур пластины, разъёмы и конфликт
   розеточного блока;
2. `/krepezh-dlya-televizora-na-stenu/` — диагностическое дерево основания,
   без автоматического назначения анкеров;
3. `/kabel-kanal-dlya-televizora-na-stene/` — маршрут и длина кабелей;
4. `/kronshteyn-dlya-saundbara-k-televizoru/` — совместимость VESA-реек;
5. `/polka-dlya-pristavki-pod-televizor/` — размер, вентиляция и коллизии;
6. `/kak-povesit-televizor-na-gipsokarton/` — сбор данных и решение «нужен
   осмотр», без обещания прочности;
7. `/stoimost-ustanovki-televizora-na-stenu/` — только с датированными
   региональными источниками цен.

Публиковать все страницы одновременно нельзя. Для каждого URL сначала нужна
отдельная функция, источник исходных правил и перелинковка; иначе это будут
тонкие SEO-дубли.

## Монетизация

Монтажная карта естественно связывает задачу с кронштейном, крепежом,
детектором скрытой проводки, уровнем, кабель-каналом, HDMI-кабелем, полкой и
креплением саундбара. Наличие награды по этим товарам пока не доказано:
публичный манифест Маркета пуст, поэтому ни товар, ни `promise`, ни доход не
показываются на странице.

После одобрения площадки коммерческий блок может появиться только после полного
расчёта, с прямой ссылкой Маркета, видимой маркировкой, ERID и
`rel="sponsored nofollow noopener noreferrer"`.
