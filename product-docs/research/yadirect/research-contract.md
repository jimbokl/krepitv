# KREPI TV — контракт исследования Яндекс Директа

Дата: 2026-07-30.

- Продукт: независимый подбор кронштейна по точной модели телевизора.
- Посадочная: `https://krepitv.ru/`.
- Целевое действие для анализа: переход к проверенным совместимым вариантам;
  запуск и расход не разрешены.
- Критерий релевантности: запрос должен относиться к кронштейну телевизора,
  VESA, механизму, высоте установки или выбору крепежа для телевизора.
- Частотность: РФ, месяц исходной выгрузки 2026-07, устройства в источнике не
  указаны.
- Прогноз Директа: Россия, поиск, рубли, месяц, все устройства. Фактические
  настройки должны быть прочитаны из интерфейса перед расчётом.
- Размер батча: 25 фраз.
- Исходник SEO: `../semantics/tv_mount_ru_keywords.csv`.
- Кандидаты: `krepitv-direct-candidates.csv`.
- Результат CPC: `krepitv-direct-forecast.csv`; до выгрузки из авторизованного
  «Прогноза бюджета» поле CPC остаётся пустым.

## Ограничение запуска

По официальной Политике дистрибуции Маркета контекстная поисковая реклама
партнёрских продуктов запрещена, а исключение для цепочки «Директ → собственная
контентная страница → Маркет» не сформулировано. До письменного разрешения
поддержки запуск заблокирован. Расчёт прогноза без расхода допустим.
