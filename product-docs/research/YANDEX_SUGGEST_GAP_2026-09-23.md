Дата сбора: 23 сентября 2026 года. Регион подсказок: Россия (`lr=225`), интерфейс на русском. Скрипт `scripts/research/collect-yandex-suggest.mjs` запросил 32 исходные фразы с паузами между запросами. Получено 293 уникальных подсказки. Исходные ответы и нормализованный список лежат в `product-docs/research/raw/yandex-suggest-20260923/`.

Это **выборка подсказок, не Wordstat и не частотность**. Подсказка подтверждает формулировку потребности, но не доказывает число показов, низкую конкуренцию или ожидаемый трафик. Эндпоинт подсказок публичный, но недокументированный: при повторном сборе выдача может отличаться. [Как Яндекс описывает подсказки](https://yandex.ru/support/search/ru/troubleshooting/searchsettings/suggest).

## Не превращаем в страницы без другой доказательной базы

Подсказки «звук телевизора для соседей/скачать/из игры» — поиск аудиофайла, не задача KREPI TV. «Настройка телевизора на дому» — запрос услуги, которой сайт не оказывает. «Кронштейн ДНС» — навигация к чужому магазину. «Телевизор в спальне/на кухне фото» — поиск интерьерных фотографий; текстовая вариация калькулятора высоты не отвечает на этот интент. Запросы по фирменным пультам и брендовым меню без подтверждённых инструкций по конкретным моделям оставлены в наблюдении, а не размножены в программные шаблоны. «Яркость в нитах» требует данных измерений по конкретной модели; сейчас нет достоверной базы для отдельного справочника.

После публикации оценивать результат по query→page данным Яндекс Вебмастера и Search Console. Не считать факт подсказки, отправку IndexNow или наличие URL в sitemap трафиком/индексацией. Если две страницы начнут ранжироваться по одной группе запросов, проверить каннибализацию перед дальнейшим расширением.
