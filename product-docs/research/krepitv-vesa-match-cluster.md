# KREPI TV — продуктовый контракт VESA Match

Дата решения: **30 июля 2026 года**.

## Решение

- Усиливаем существующий URL `/vesa/`; новый `/kalkulyator-vesa/` не создаём.
- Пользователь получает самостоятельный результат без регистрации, сервера и
  товарной карточки.
- Расчёт выполняется локально в Rust/WASM.
- Партнёрские предложения допустимы только после ответа и только по правилам
  прямой маркированной ссылки; для запуска инструмента они не нужны.

## Подтверждённый спрос

В сохранённом срезе XMLRiver Wordstat для России:

- `крепление vesa` — **2 391** показ/мес;
- `vesa кронштейн` — **2 244**;
- `кронштейн vesa` — **2 218**;
- `стандарт крепления vesa` — **317**.

Фразы пересекаются, поэтому значения нельзя складывать и называть уникальными
пользователями. Источник: `semantics/tv_mount_ru_keywords.csv`, строки 35, 38,
40 и 122.

## Продуктовый клин

Пользователь:

1. вводит горизонтальное и вертикальное расстояние между центрами отверстий
   телевизора;
2. выбирает единицу измерения — миллиметры или сантиметры;
3. вставляет строку поддерживаемых VESA из характеристик конкретного
   кронштейна;
4. получает один из трёх ответов: `пара явно поддерживается`, `пара отсутствует`
   или `данных недостаточно`.

Парсер должен понимать `x`, кириллическую `х`, знак `×`, миллиметры,
сантиметры и перечни пар. Он показывает нормализованный размер ширина×высота,
распознанные пары и возможную перестановку осей.

## Граница безопасного ответа

- Формулировка `до VESA 600×400` или `максимальный VESA 600×400` не доказывает
  поддержку всех меньших размеров. Такой ввод даёт только `данных
  недостаточно`.
- Совпадение должно опираться на явно перечисленную точную пару.
- Порядок осей значим: сначала горизонталь, затем вертикаль.
- При близком, но неточном ручном замере показывается кандидат для повторной
  проверки, а не зелёное совпадение.
- Совпадение VESA не называется полной совместимостью. Отдельно проверяются
  масса телевизора, допустимая нагрузка, диагональ, винты, механизм, кабельные
  зазоры и основание стены.

## Разведение интентов

- `/vesa/` — определение пары и проверка строки характеристик кронштейна;
- `/kak-uznat-vesa-televizora/` — инструкция поиска модели и ручного замера;
- `/vesa/200x200/` и другие подтверждённые точные страницы — работа с уже
  известной парой;
- `/podbor/` — проверка по точной модели телевизора.

## Конкурентный срез

Русская выдача в проверенном срезе содержала преимущественно статьи и товарные
категории: Price.ru, Технопарк и материал Ивана Корнева. Узкого русскоязычного
интерактивного инструмента, который сравнивает ручной замер с вставленной
строкой характеристик кронштейна, среди просмотренных результатов не найдено.
Это качественный вывод по срезу, не измеренный коэффициент конкуренции.

## Критерии публикации

- Rust-тесты покрывают разные знаки умножения, мм/см, точное совпадение,
  отсутствие пары, перестановку осей, неточный замер и формулировку
  `максимальный VESA`;
- публичный интерфейс полностью русский, кроме технического обозначения VESA;
- исходный HTML содержит обновлённые title, description, H1, факты и FAQ;
- страница не создаёт новые индексируемые URL под автоматически распознанные
  размеры;
- desktop и mobile проходят визуальную и интерактивную проверку до релиза;
- в результате нет affiliate-ссылок, скрытых переходов или обещаний полной
  совместимости.

## Статус реализации

Реализовано 30.07.2026 на существующем URL `/vesa/`. Парсер и вердикт работают
в Rust/WASM, React отвечает только за форму и представление. Пройдены unit,
sitegen, русский UI, desktop/mobile browser E2E и совместное визуальное
сравнение с утверждённым внутренним референсом. Публикационный статус
фиксируется только после успешного production-деплоя.
