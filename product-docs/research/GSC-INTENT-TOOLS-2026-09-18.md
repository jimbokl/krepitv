# Спринт по интентам Google Search Console — 18 сентября 2026

Окно GSC: **1 августа — 16 сентября 2026**, тип «веб», финальные данные. Суммарно по сайту: **6 049 показов и 111 кликов**. Выгрузка без порога видимых запросов дала **428 строк запросов и 439 связок «запрос → страница»**, без усечения по лимиту API. Google скрывает часть низкочастотных запросов из-за приватности: эта выгрузка **не является полным перечнем всех поисковых фраз**. Суммы по строкам запросов нельзя выдавать за общий трафик сайта.

Все 428 видимых фраз прошли первичную взаимоисключающую группировку по намерению: расход энергии — 128, подключение и настройка — 67, крепёж/VESA — 40, субтитры и голос — 24, неисправности — 20, размеры/расстояние — 17, модели/марки — 18, прочие и неоднозначные — 114. Это грубая классификация по словам, а не достоверный объём спроса по темам: фраза может затрагивать несколько задач. Энергопотребление уже закрыто отдельным действующим калькулятором; модельные запросы ведут на паспортные карточки. Новые инструменты выбраны для выявленных сценариев, где пользователь после чтения инструкции всё ещё должен принять решение.

Решение: **не создавать новые URL**. На двадцати существующих канонических страницах с показами углубить уже опубликованные руководства: пользователь выбирает наблюдаемый сценарий, выполняет безопасный первый шаг и явно отмечает результат. Для «помогло» и «не помогло» показаны разные следующие действия. Статическая таблица, ограничения и ссылки на официальные инструкции остаются доступны без интерактивности. Ни один инструмент не делает неподтверждённых выводов о технической совместимости или ремонте.

Источники данных: приватные выгрузки GSC от 18 сентября 2026 в `.private/search/`; внутри репозитория сохранены только агрегаты и формулировки интентов.
