# KREPI TV — решение по следующей SEO-волне

Дата решения: 2026-07-31. Сбор: Россия, все устройства, Wordstat Top queries через XMLRiver. Реклама и расходы не запускались.

## Контракт

- Продукт: независимый подбор кронштейна по точной модели телевизора.
- Конверсия: пользователь получает проверку совместимости и при желании переходит по прямой партнёрской ссылке на Яндекс Маркет.
- Релевантность: только выбор и покупка кронштейнов для телевизоров из проверенного каталога; монтажные услуги, мебель, мониторы и прочие крепления исключены.
- Операторный замер: кавычки фиксируют число слов, квадратные скобки — порядок, `!` — словоформу. Частоты разных формулировок не складываются.
- Основная метрика: `popular[].value` из вкладки Top queries. `history.totalValue` не применяется к операторному замеру, потому что в «Динамике» Яндекс поддерживает только оператор `+`.

Методика подтверждается [справкой Яндекса по операторам](https://yandex.ru/support2/wordstat/ru/content/operators), [гайдом Яндекса по частотности](https://direct.yandex.ru/base/articles/zachem-i-kak-utochnyat-chastotnost-zaprosov) и [форматом Top queries XMLRiver](https://xmlriver.com/apiwordstatnew/apiwn-words/).

Числа описывают обращения к формулировкам, а не прогноз визитов или выручки. У ONKRON API вернул одинаковое значение для единственного и множественного числа; это не суммируется и рассматривается как один сильный брендовый сигнал.

## Почему страницы не будут дорвеями

1. Каждая страница решает отдельную задачу: коммерческое сравнение, требуемый вылет механизма или выбор внутри бренда.
2. Каталог строится из проверенных характеристик и графа совместимости, а не из переписанных описаний Маркета.
3. Длинные каталоги группируются по брендам и скрываются в нативных раскрывающихся блоках.
4. Пользователь может получить технический результат без покупки и регистрации.
5. Цены не копируются: региональная цена и наличие проверяются только на стороне Маркета.

## Артефакты

- Основной батч: `data/research/seo-hub-demand.json`.
- Контроль порядка и кириллицы: `data/research/seo-hub-demand-controls.json`.
- Строгие словоформы: `data/research/seo-hub-demand-strict.json`.
- Неизменённые ответы: `product-docs/research/raw/wordstat-seo-hubs-2026-07-30/`, `wordstat-seo-hub-controls-2026-07-30/`, `wordstat-seo-hub-strict-2026-07-30/`.

Следующее решение принимается уже по фактическим показам, кликам, органическим визитам и подтверждённому вознаграждению; сами частоты успех не доказывают.
