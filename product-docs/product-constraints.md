# KREPI TV — обязательные ограничения продукта

Дата фиксации: 2026-07-30.

## Цель

Довести KREPI TV до 100 000 ₽ подтверждённого ежемесячного вознаграждения
по партнёрской программе Яндекс Маркета после отмен и возвратов.

## Рынок и язык

- Продукт работает только для российского рынка.
- Весь публичный интерфейс, SEO-страницы, подсказки, ошибки, письма и
  метаданные сайта должны быть только на русском языке.
- Английские слова допустимы только как официальные маркировки и стандарты,
  которые нельзя корректно перевести: VESA, HDMI, USB, SKU и названия моделей.
- В пользовательском интерфейсе не должно быть английских служебных строк,
  заглушек или кнопок.

## Продуктовый клин

Сервис не является общим каталогом электроники. Он отвечает на один точный
вопрос: какой кронштейн и крепёж совместимы с конкретной моделью телевизора и
как правильно рассчитать высоту установки.

Главный сценарий первого экрана:

1. Пользователь вводит точную модель телевизора.
2. Получает подтверждённые VESA, массу, габариты и ограничения монтажа.
3. Видит только совместимые кронштейны с объяснением совместимости.
4. Переходит на Яндекс Маркет по размеченной партнёрской ссылке.

## Технологические ограничения

- Максимум логики выполняется локально в Rust/WASM.
- Хостинг — бесплатный статический GitHub Pages.
- Cloud.ru не использовать.
- Интерфейс реализуется на Tailwind CSS по выбранному визуальному референсу.
- Все характеристики должны иметь источник и дату проверки; неизвестные данные
  нельзя выдумывать.

## Дизайн

- Доверие к технической точности важнее декоративности.
- Первый экран обязан сразу показывать ввод модели телевизора и понятный
  результат, а не абстрактное описание продукта.
- Не использовать шаблонный «вайбкодерский SaaS»: россыпь карточек, лишние
  метрики, стеклянные градиенты и декоративные панели без функции.
- Мобильный сценарий должен быть полноценным, поскольку большая часть
  коммерческого SEO-трафика ожидается со смартфонов.
