Для каких телевизоров подходит iTECHmount PLB440NT?

iTECHmount PLB440NT — наклонная модель для телевизоров 32–75″, рассчитанная на нагрузку до 45 кг. Текущий граф содержит 115 подтверждённых совместимых моделей.

Поддерживаются 200×200, 200×300, 300×200, 200×400, 400×200, 300×300, 300×400, 400×300 и 400×400.
