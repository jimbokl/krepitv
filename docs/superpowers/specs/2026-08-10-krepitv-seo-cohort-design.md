# KREPI TV: SEO-когорта 10 августа 2026 — дизайн

## Цель

Опубликовать десять самостоятельных русскоязычных руководств с подтверждённым спросом. Каждая страница должна закрывать один интент, давать локальный мастер из трёх веток, сравнительную SSR-таблицу, безопасную границу, FAQ и минимум два официальных HTTPS-источника.

## Состав когорты

1. Подключение телевизора к интернету — единый canonical для Wi‑Fi, LAN и точки доступа телефона.
2. Подключение телевизора к Алисе — выбор между YaOS/ТВ Станцией, Модулем и поддерживаемой интеграцией.
3. Перезагрузка телевизора — только мягкий перезапуск и отключение питания, без смешения со сбросом данных.
4. Включение Bluetooth — проверка наличия профиля и режима сопряжения; наушники и колонки остаются отдельными сценариями.
5. Первичная настройка Smart TV — сеть, аккаунт, обновление и базовая конфигурация.
6. Подключение камеры — HDMI для сигнала, USB для поддерживаемого медиарежима, IP-камера через совместимое приложение.
7. Подключение DVD — HDMI, прямой аналоговый вход или активный преобразователь; пассивный кабель не объявляется конвертером.
8. Установка браузера — встроенный браузер, официальный магазин ОС или отсутствие поддерживаемой установки.
9. Телевизор без кронштейна — только штатная подставка на устойчивой мебели либо подтверждённое крепление; самодельный подвес не предлагается.
10. Включение HDR — проверка совместимости телевизора, источника, порта, кабеля, контента и режима входа.

## Визуальное решение

Полностью повторно используется утверждённый Tailwind-шаблон `SeoEvidenceGuide`: paper/ink/action/muted/line, крупный заголовок, три нативные кнопки, локальный результат, SSR-таблица, стоп-блок, источники и связанный путь к подбору кронштейна. Новых компонентов, иллюстраций и дизайн-токенов нет.

## Состояния и доступность

- Без JavaScript остаются H1, факты, все три строки таблицы, стоп-блок, источники, FAQ и ссылка на подбор.
- Выбор ветки работает локально, результат объявляется через `aria-live`, кнопки используют `aria-pressed` и видимый `focus-visible`.
- На 320, 768 и 1440 CSS px документ не имеет горизонтального overflow; широкая таблица прокручивается только внутри своего контейнера.
- Loading/error не нужны: сетевого запроса и серверного расчёта нет; SSR является полноценным fallback.

## Контентные границы

Ни одна страница не публикует цену и не содержит ссылку Маркета. Технические советы не заменяют паспорт конкретной модели. Близкие интенты объединяются в одну страницу или явно разводятся с существующими canonical. Все мастера заканчиваются безопасным следующим шагом к точной модели и проверенному кронштейну.

## Приёмка

- Ровно 10 уникальных id/path в датированной когорте, одна exact Wordstat-частотность на страницу.
- На каждой странице: 6+ фактов, 6+ FAQ, ровно 3 шага мастера, stop, 2+ официальных HTTPS-источника.
- У каждой новой страницы есть входящая и исходящая внутренняя ссылка.
- Sitemap увеличивается с 277 до 287 индексируемых URL.
- Полный `npm run build`, design drift и визуальная проверка трёх viewport проходят.

## Откат

Откатить один source-коммит когорты, пересобрать `docs/` и повторно опубликовать GitHub Pages. Серверного состояния и миграций нет.
