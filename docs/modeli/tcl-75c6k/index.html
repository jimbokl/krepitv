Подбор по точной модели

Как подобрать кронштейн для TCL 75C6K?

Для TCL 75C6K нужен кронштейн с VESA 300×300, паспортным диапазоном для 75″ и нагрузкой с запасом относительно массы 23 кг. Международная спецификация точной модели указывает 4 винта M6×16; все три проверки прошли 7 моделей.

Какой VESA у TCL 75C6K?+

Для этой точной модели указан VESA 300×300 мм. При крупной диагонали отдельно проверяются нагрузка и геометрия пластины.

Какие винты нужны для TCL 75C6K?+

Международная спецификация точной модели указывает 4 винта M6×16. Для российского экземпляра перед покупкой нужно сверить руководство.

Какие кронштейны полностью совместимы?+

Подтверждены 7 моделей, включая ONKRON TM6, KROMAX ATLANTIS-65 и iTECHmount PLB640NT.
