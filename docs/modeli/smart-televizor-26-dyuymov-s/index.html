Три проверки до покупки

Как подобрать кронштейн без ошибки

  1. 01 · Модель

    Сверьте шильдик

    Сравните полный код на задней панели с «телевизор 26 дюймов с». Суффикс и диагональ могут менять корпус, массу и VESA.

  2. 02 · VESA

    Измерьте отверстия

    Снимите подставку только по инструкции. Измерьте горизонталь × вертикаль между центрами четырёх резьбовых отверстий.

    Инструкция по VESA →
  3. 03 · Масса

    Найдите вес без ножек

    Берите массу без подставки из руководства и закладывайте минимум 25% запаса. Стеновой крепёж проверяется отдельно.
