# Винты VESA для популярных в России моделей телевизоров

Открытая проверяемая выгрузка KREPI TV: точная модель телевизора → VESA →
резьба и паспортная длина либо диапазон зацепления → официальный источник.
Данные собраны для точных кодов моделей и не переносятся между похожими
сериями или диагоналями. Регион каждого официального источника указан явно:
для части моделей российская инструкция не публикует нужный размер, поэтому
использован документ производителя из другого региона без подмены его статуса.

## Скачать

- [CSV, версия 1](v1/tv-vesa-screws.csv)
- [JSON, версия 1](v1/tv-vesa-screws.json)
- [Живой поиск по модели](https://krepitv.ru/vinty-dlya-krepleniya-televizora/)

Выгрузка содержит только модели, для которых найден официальный паспорт
настенного монтажа. Цен, остатков, партнёрских ссылок и предположений по
соседним моделям здесь нет.

## Как читать размеры

- `exact_length` — руководство прямо задаёт полную длину винта;
- `engagement_range` — дан диапазон `L` или `C`, который нельзя считать
  готовой длиной без толщины пластины, шайбы или проставки;
- `length_unknown` — производитель подтвердил резьбу, но не безопасную длину;
- `adapters_status=unknown` — наличие проставок в источнике не подтверждено.

Одна строка соответствует одной группе винтов одной модели. Если официальные
источники расходятся, это явно отмечено в `vesa_source_conflict` и
`conflict_note`.

## Поля происхождения

Для каждой строки сохранены регион источника, дата проверки, название
документа, его HTTPS-адрес и, когда он есть, второй официальный источник.
Перед монтажом перепроверьте бумажную инструкцию конкретного телевизора и
кронштейна: датасет не заменяет требования производителя и проверку стены.
