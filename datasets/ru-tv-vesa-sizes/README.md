# Размеры VESA популярных в России телевизоров

Открытая проверяемая таблица KREPI TV: точная модель телевизора → размер VESA
по горизонтали и вертикали → официальный источник. Записи привязаны к полным
кодам моделей и не переносятся между похожими сериями или диагоналями.

## Скачать

- [CSV, версия набора 2.0.0](v1/tv-vesa-sizes.csv)
- [JSON, версия набора 2.0.0](v1/tv-vesa-sizes.json)
- [Неизменяемая копия релиза 2.0.0](https://github.com/jimbokl/krepitv/releases/tag/datasets-v2.0.0)
- [Живой поиск и ручная проверка VESA](https://krepitv.ru/vesa/)

Выгрузка не содержит цен, остатков или партнёрских ссылок. Для каждой строки
указаны дата проверки, официальный HTTPS-источник и карточка точной модели с
проверенными кронштейнами.

## Ограничения

VESA подтверждает только расположение отверстий. Перед покупкой и монтажом
отдельно проверяют массу телевизора, диапазон диагоналей, винты, проставки,
геометрию пластины, разъёмы и основание стены. Если официальная карточка и
руководство расходятся, поля `vesa_source_conflict` и `conflict_note` требуют
ручного замера вместо автоматического выбора одного значения.
